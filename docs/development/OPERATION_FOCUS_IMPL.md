# Focus 读取失败时的草稿保留

2026-09-21，定点实施独立审核发现的问题。沿用 [操作交接契约](../design/operation-refresh/HANDOFF.md)，不改变 Ocean 视觉、计时事实、仓储或数据格式。

## 状态契约

- FocusPage 保留最后成功查询的显示快照；后台读取失败不卸载开始表单，因此标题、时长、分类、备注以及 dirty/busy 导航保护保留。
- 失败有明确提示和“重试读取”。重试仅重新订阅，不写数据。开始专注成功后也重新订阅，避免失效订阅无法显示已经持久化的活动会话。
- 显示快照不是数据库，也不作为自动完成的权威：自动完成继续使用成功查询结果及原仓储的时间戳/事务保护。
- 专注详情编辑错误使用 preventScroll 聚焦，只将字段容器滚到顶部；删除/放弃确认打开时不抢走原生对话框焦点。保存失败仍保留输入与原计时事实。
- 新日志仅含固定操作、状态和失败类别，不含标题、备注、时间或其他私人记录。

## 回归范围
