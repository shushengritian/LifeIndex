# LifeIndex 4.0 应用流程与共享界面

2026-09-29，根协调实现；处于生产独立验收，尚未发布。依据已冻结的 DESIGN_SYSTEM、ARCHITECTURE 与 TEST_STRATEGY。

## 入口、服务和状态

`src/main.tsx` 进入 `AppV4`，路由是 Hash Router。`AppProvidersV4` 为页面生命周期提供唯一服务实例；数据库打开失败只提供重试，不删除或重建记录。新业务只使用 LifeIndexV4；旧模块保留用于历史回归，不被新版入口引用。

页面用稳定 query 回调订阅 `useV4Query`。query 身份变化立即切换到新请求状态，不把旧日期/实体快照当作新页面；failed 保留事实但展示失败及重试，不伪装空库。外观偏好实际读取并应用后才令 html 的 `data-theme-state` 为 ready，性能采集不能把 system 回退主题当作偏好已就绪。

`FocusController` 统一负责开始、暂停、恢复、人工/自然结束及重试，外部 store 只让需要时间的组件每250ms更新。待完成端点固定，prepare 与 finalize 分开持久化；不足一秒不能进入无法保存的状态。设备墙钟偏离可信单调时钟时冻结显示并拒绝暂停/结束写入，校正后显式重试；不能将异常跨度计入时长。未保存会话或写入中参与更新保护。

## 导航、录入、回执和焦点

全局“留一笔”打开记录类型选择层，再进入金额/体重/运动编辑器。全局默认日期在创建时捕获今天，只有显式“记下这一天”的领域动作传入日期。编辑器固定初始 generation、entity revision 和草稿，实时查询不能覆盖正在编辑的内容；保存意图 commandId 在失败重试间保持稳定。

`FlowProvider` 只在内存中保存至多20个来源会话：路由/查询参数、滚动位置及语义 focus key；URL 不含草稿。保存、取消返回来源会话，DOM 重建后按 key 恢复焦点，无有效来源时回领域页面。保存回执显示实际记录日期，并以服务返回的实体ID提供“查看记录”，不偷偷改变来源筛选。

Modal 使用原生 dialog 和可访问标题，主输入获得焦点；显式处理正反 Tab 首尾循环，避免焦点进入浏览器界面。确认弹层是当前活动层，Escape/取消由调用方检查 busy 和脏表单；关闭后恢复有效来源元素。所有保存和删除防重复，失败留输入和错误；`useDirtyGuard.release()` 在成功导航前同步释放保护，避免保存成功仍弹丢弃确认。

`NavigationGuard` 拦截脏草稿离开；写入中拒绝导航，未保存输入需确认。PWA更新沿用现有应用外壳缓存机制，存在草稿/写入/待保存专注时禁用立即更新。实际 dock 高度写入布局变量，为320px和大字时多行导航预留空间。

## 设置与备份

外观在本地偏好中保存 system/light/dark；分类管理由领域作者实现真实创建、编辑、排序、归档、重新启用和未引用删除。

备份页在每次文件选择前递增读取代次，取消/离页使旧结果失效并释放 preview token。原生文件 input 取得 File 对象后清空 value，允许取消后重选同一文件。校验/预览不写业务表；替换确认后再执行服务原子恢复，失败保持当前库。恢复中参与 busy guard。导出先取得一致快照并交给浏览器下载，再记录导出时间；界面明确仍需确认文件已保存。

## 资源、日志与检查

样式只从 v4 tokens/base/shell/forms/settings/features 加载；不引入旧全局样式。Manrope、原创 SVG 和应用图标随外壳离线缓存，没有字体 CDN、付费 API 或图片请求。版本来自 package.json 4.0.0，并暴露 `data-app-version` 供实际构建核验。

关键入口、状态变化与失败使用现有 allowlist logger，只记录固定操作/实体类型/失败分类。金额、日期、记录ID、备注、名称和文件内容不进入日志。UI文本可显示真实记录，测试只用隔离合成库。

第一版生产构建已完成，类型及相关lint通过；独立测试正在运行。首轮暴露的浅色习惯计数对比度、Tab越界、文件同名重选已修订，最终通过状态以 `PRODUCTION_REVIEW.md` 的新构建复测为准。测试自身的200%字号累积及计时起点早于start提交已由独立测试作者修正，不能混写成产品缺陷。浏览器主入口 `pnpm test:e2e` 指向V4契约；旧DOM套件保留为 `pnpm test:e2e:legacy`，不会用历史通过数代替V4验收。

## 独立审核修订

Safari 实际 click capture 在带语义 key 的触发器上显式聚焦，然后 Flow 才捕获来源；不会在滑动开始时抢焦点。Modal 显式提供初始焦点和每步 Tab 前后推进，覆盖 WebKit 跳过按钮的原生偏好。习惯操作由 React 提交 enabled DOM 后的 layout effect 恢复焦点，替代可能早于 disabled=false 提交的单帧回调。

记录编辑的初始 source 由编辑会话持有，另一标签删除/恢复记录或只读订阅失败不会卸载草稿；保存仍用原身份/代次，冲突保留输入。专注结束/放弃及自动完成绑定调用时的 generation、session ID 和 revision；读取最新状态只作一致性核对，不能用新的当前会话替换被确认目标。会话身份切换使旧确认中止。FocusGuard 分别订阅未持久草稿与 busy 布尔量，保护所有未决写入而不随每个计时tick重渲染。

设置页只在 ready 时断言是否导出过备份，失败有局部重试。专注详情按实体捕获的 UTC offset 展示起止时刻并标注 offset，与列表的事实时区一致，跨日终点不强制改写为开始日。

公开构建标识 `LIFEINDEX_BUILD_ID` 优先、GitHub Actions 的 `GITHUB_SHA` 次之、本地默认 local，注入 `data-app-build`；仅允许80字符内字母数字/点/下划线/连字符，不包含密钥。CI线上冒烟以精确SHA核对部署，本地A/B更新测试可用不同公开标识构建同源版本。`pnpm test:deployed` 使用V4实际路由和新库，`test:deployed:legacy` 保留历史套件。Node类型检查纳入所有V4浏览器/性能/部署测试。

全量Vitest初跑284过/1旧测试硬编码3.3.0失败；该断言已改为当前构建版本合同，单文件8项复测通过。新版controller原3项回归在本轮修订后通过。最终全量结果仍待完整候选集成后收口。

## 首次访问后的更新接管修订

PWA更新只有UI保护允许后才登记一次批准。接管监听在发送SKIP_WAITING之前建立，并比较旧/新controller；即使首次访问时Workbox固定isUpdate=false，也会在新worker接管后刷新一次。插件onNeedReload不再自动刷新未批准的页面，避免另一标签激活更新时丢弃草稿。30秒未接管或发送失败会清理监听并返回失败，解除applying状态供重试；日志仅包含操作和失败类别。真实A→B双引擎验收由独立QA执行，未以代码推断通过。

更新失败在状态栏显示可见重试，并捕获拒绝Promise；applying期间更新按钮禁用，防止重复提交。

## 主导航滚动修订

独立真实滚轮+底栏点击确认：旧页面滚动位置可能沿用到另一主页面，使新标题和主操作位于视口上方。主导航、品牌首页和设置入口显式标记navigationStart，路由PUSH成功后滚动至页首并聚焦main；发生脏草稿阻拦时不会提前移动页面。Flow关闭使用REPLACE，不触发主导航复位，保存/取消仍按原会话恢复滚动和焦点，报表返回独立契约保持。日志记录固定primary-destination原因，不记录路由参数或个人数据。
