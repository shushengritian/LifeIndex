## 数据与返回行为

- 所有查询仅经core服务。分页交易/运动/专注与分类并行读取后核对generation/revision，一次组合查询最多重读3次；持续变化抛ReadFailure，不拼接混代数据。历史50条一页，页面有下一页和回到第一页；月份/日期变更清游标。
- Today完整轨迹的limit根据用户操作20条递增，core确认此接口不套用普通分页100条上限。统计总数来自服务，不拿已显示条数充当总数。计划进度用scheduledCompletedCount/scheduledCount；非计划事实保留轨迹。
- 体重图每日期使用服务提供的当日最后录入，少于两个日期不连线；图外可见起终值/变化kg，日期记录不伪造分钟。
- 月报普通Link保留可打开新标签的语义；正常激活捕获来源URL、滚动和data-focus-key。返回后等待来源记录就绪再恢复。修改报表月份和分页不覆盖来源状态。
- 习惯整行动作与详情Link互为兄弟控件。写入捕获desired状态并使用ref同步锁；失败留原记录，成功由live query反映。详情/计划编辑不会借查看命令完成习惯。
- 习惯/目标草稿捕获原snapshot和stamp；不随live query自动换代。脏退出由根useDirtyGuard与显式取消确认配合，保存成功先release再导航。输入校验使用统一边界；目标调用parseWeightInput。
- 习惯、目标和分类写入通过`v4/intent.ts`保留同一失败意图的commandId与原stamp，不自动刷新revision重提；输入或动作变化才创建新意图，确认成功后清理。内存签名包含输入以识别相同意图，永不记录到日志。局部写入忙碌也纳入全局离开/更新保护。
- 分类编辑捕获原scope与stamp；实体领域不可变，归档项允许先改名再启用。duplicate/冲突保留输入与归档状态，已有记录引用不被删除。CategoryEditor与目标编辑都复用根Modal、初始焦点和取消保护。
- 分类归档/启用会跨列表移动节点，必须等命令返回stamp对应的查询渲染后恢复焦点；排序回原方向控件（边界则编辑），归档/启用回同分类编辑，删除回新增。
- 专注计时、失败保存、刷新与并发归根FocusRuntime。领域页面保持同一主控按钮节点与键盘焦点，pending不显示继续运行文案，不把未保存时长计入统计。
- 专注运行/暂停中出现控制器错误时提供“重试专注状态”，明确调用runtime.retry；墙钟异常不会陷入普通暂停/继续不断被拒绝的死路。待保存仍使用“重试保存”，读取失败仍使用读取重试。
- 日历日期以UTC中午计算星期/相邻自然日避免DST边界，显示日期来自服务clock.capture()。页面今天每30秒及visibility/focus重查，仅本地日期变化更新；不会改动已打开草稿日期。

## 输入名称和测试接点

习惯accessible name：`完成{名称}`、`撤销完成{名称}`、`查看{名称}详情`。计划输入label为“习惯名称”“每周重复 · 至少选择一天”“习惯图形”“备注（选填）”，提交“保存习惯”。健康动作“记体重”“记运动”“设置目标”，目标label“目标体重（kg）”。记账动作“记一笔”，视图“本月流水”“按日查看”，报表“月报表／本月报表”，返回“返回原页面”。专注动作“开始专注／暂停一下／继续专注／重试保存”，控制器确认结束/放弃。

日志仅记录固定operation/entityType/reason/fromState/toState/failureClass，不记录标题、金额、体重、具体日期、ID或输入。关键快照、desired状态、返回与草稿保护均有责任注释。旧领域源码/历史单测未改动，也不作为新界面验收证据。
