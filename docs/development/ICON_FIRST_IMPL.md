实施现已完成，本地验证记录见3.2.0发布记录；线上交付状态以该发布记录与根PLAN为准。

## 分工与实现

- TodayPage：整宽摘要链接与新增兄弟分区；查看专注直接进入已有history路由。记录只读与写入日志分开，不记录金额或标题。
- FinancePage：报表移到月历汇总后内容行，仍保留日历月份/日期/滚动与焦点返回；不改变聚合。
- Sheet：可选headerAction，等宽两翼实现X/居中标题/保存；原生form关联提交，不复制提交函数。Finance表单保留真实日期、备注、二级分类、输入校验、busy锁、失败保留和脏草稿保护。
- 通用content-entry：最小64px、间距16px，图标只作提示；icon-action最小44px；今日节标题居中、距内容16px。CSS只隐藏滚动指示器，不禁用内容滚动。
- 专注与健康的实现说明见本目录对应ICON_FIRST文档；不移植原型模拟数据层。
