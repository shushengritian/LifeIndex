# 当前 UI 契约

应用版本由 `__APP_VERSION__` 提供，采用语义化版本，当前为 `3.3.0`。关于页显示应用版本、存储方式和离线能力；不展示数据库版本。

健康提供体重、运动与习惯。首页内容区域进入历史或详情，标题旁的新增操作进入录入流程。设置提供分类、外观、数据与安全、关于入口。

健康历史、专注历史及独立习惯页使用页头左侧的左箭头返回控件，触控区域至少 44 × 44 CSS px，没有可见返回文字。无障碍名称明确目的地（返回健康、返回专注或返回今天），图标不单独朗读。习惯从今天进入时保留返回焦点与滚动所需的来源状态；专注历史返回不改变计时状态。导航日志仅记录操作与固定业务上下文。

图标化不影响字段标签、错误反馈、保存保护或破坏性操作的文字确认。恢复备份仍先校验、预览并明确确认替换；删除与放弃修改仍需确认。备份读取日志仅记录当前格式 5 的检查契约，不记录文件名或备份内容。

沿用 Ocean 深浅主题、现有焦点反馈和 SVG 图标系统。浏览器检查不代表 iPhone 真机验收。
