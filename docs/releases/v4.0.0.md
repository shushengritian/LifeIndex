优先回退到已验证的4.x源码/静态产物，保持同一HTTPS来源、base path及新版数据库；通过正常SW更新重新加载。若必须回退3.3源码，新版记录仍留在独立库但旧界面不能显示它，不能声称数据已迁回旧库。不要清空IndexedDB、改变业务origin或用旧备份覆盖新版来解决应用显示问题。
