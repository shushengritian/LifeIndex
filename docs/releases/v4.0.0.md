## 发布与回退

沿用既有[GitHub Pages入口](https://shushengritian.github.io/LifeIndex/)，经PR独立审核、CI、合并后的Pages构建/部署/线上冒烟逐级验证。构建通过不等于已上线；线上校验package版本及 `data-app-build` 对应GITHUB_SHA，并验证资源子路径、持久化、核心任务和离线。

优先回退到已验证的4.x源码/静态产物，保持同一HTTPS来源、base path及新版数据库；通过正常SW更新重新加载。若必须回退3.3源码，新版记录仍留在独立库但旧界面不能显示它，不能声称数据已迁回旧库。不要清空IndexedDB、改变业务origin或用旧备份覆盖新版来解决应用显示问题。

数据异常先保存可导出的新版备份与错误类别，做兼容新库的修复；源码回退和数据恢复是不同操作。备份、个人记录、凭据及生成dist不进入Git。
