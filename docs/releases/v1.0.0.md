## Data and update contract

- Application `1.0.0`; IndexedDB schema **1** and backup format **1** are unchanged from `0.1.1`.
- No business logic, dependency, data migration, or automatic record deletion is introduced by this release.
- Keep the same Home Screen icon and URL. While online, reopen/return to LifeIndex; when the new-version prompt appears, save or cancel drafts and choose **立即更新**. Do not uninstall or clear Safari data to update.
- Export important data from Settings to Files/iCloud Drive. Backups are user-initiated, not automatic or cloud synchronization.
- Unknown/future backup versions are rejected before replacement. Future database changes require a separately tested migration; simply redeploying older code cannot be assumed to downgrade data safely.
- No project license is added or implied. The owner's license decision remains separate.
