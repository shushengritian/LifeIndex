# LifeIndex 2.2.0 — Ocean

状态：2026-09-20 已部署并通过线上检查。用户批准先部署 App 后 iPhone 验收，见 [ADR-0015](../adr/0015-ocean-deploy-before-device-acceptance.md)。真机仍待验收。

## 本次更新

- Ocean 浅色/深色界面、图标按钮、应用内确认与受保护表单。
- 导航为今天、健康、专注、记账、设置；今天“记一笔”保存/取消自动返回。
- 日历记账、每日支出曲线、两级分类及 42 个分类图标。
- 健康完整历史、习惯详情/可查看日期的热力图、戒烟记录入口与时间输入修复。
- 专注历史和详情、失败重试，以及分类/外观/数据与安全/其他独立设置入口。
- V4 分类索引与备份，旧数据增量升级；保留本地优先和离线写入。

## 更新与验收

1. 从平时使用的主屏幕图标打开，联网等待发现新版本。
2. 完成或放弃未保存草稿后，使用更新提示激活新版；不要删除 App、清理网站数据或覆盖导入来解决缓存问题。
3. 设置 → 其他 → 关于 LifeIndex，确认应用版本 **2.2.0**。
4. 如有重要记录，更新前建议导出备份并确认文件存在；更新后核对记录与分类，再用合成记录测试保存/编辑/取消。
5. 完成 [iPhone 验收单](../operations/OCEAN_DEVICE_ACCEPTANCE.md)。手机专属项目尚未验证，不以自动化代替。

## 已知边界

- Safari 与主屏幕入口是否进入同一账本必须在实际设备验证；发现不同账本时停止测试，不清除或覆盖数据。
- WebKit 自动化离线壳重载专项保留 1 项跳过；离线写入另有覆盖。
- V4 数据库不能配合仅支持 V3 的旧客户端回滚，发现问题应发布兼容 V4 的修复版。
