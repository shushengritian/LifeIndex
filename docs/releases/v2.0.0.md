## Data and updates

Application 2.0.0 uses additive IndexedDB schema 2 and backup format 2. Existing V1 records retain their semantics; V0/V1 backups are validated and migrated in memory before atomic replacement. Keep the existing icon and URL. When an update is offered, save or cancel drafts and select “立即更新”. Do not clear Safari website data to update. Export important records regularly; there is no cloud sync. Older application code must not be assumed to downgrade database schema safely.

The license remains unselected. No personal records, backups, build archives, or credentials are published as release assets.
