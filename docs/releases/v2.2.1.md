# LifeIndex 2.2.1 — 分类与入口精简

状态：2026-09-20 发布准备中，尚未取得本版本线上成功证据。

## 更新内容

- 分类管理改为紧凑一级列表、三点操作菜单和二级名称标签；保留排序、归档与历史引用。
- 二级分类只填写名称，不再选择独立图标/颜色；旧值兼容保留。
- 顶部仅保留页面上下文，移除本机状态徽标。
- 删除外部记账入口、模板、配置导出与交易链接处理；旧记账链接拒绝且不写入数据。
- 今天“记一笔”、应用内记账、健康、专注、备份与离线能力保持。

## 数据与更新

数据库与备份继续 V4，不改写已有记录、不清库。历史回执保留读取/恢复兼容，不开放旧运行入口。不要删除主屏幕应用或清理网站数据来更新。

联网打开平时使用的入口，保存或放弃草稿后确认更新，再到“设置 → 其他 → 关于 LifeIndex”核对 **2.2.1**。如果有重要记录，建议保留一份已确认存在的备份。

## 验证边界

最终 2.2.1 版本已重新通过类型、lint、格式、206 项单元/集成、生产构建及 67 项双引擎浏览器回归（1 项原有 WebKit 离线全页重载跳过）。四份原型控制器和文档本地链接检查通过。此前功能批次的本地 smoke 为 13 通过/1 原有跳过；CI、Pages 与线上 smoke 证据待补充，不使用旧版成功证明新版部署。

手机安全区、软键盘、主屏幕更新、Files、VoiceOver、后台计时等继续按 [设备验收单](../operations/OCEAN_DEVICE_ACCEPTANCE.md)实际确认；自动化不记为物理 iPhone 通过。
