## Updating

Keep the existing URL and Home Screen icon. Open online, save or cancel drafts, select “立即更新” when offered, then check Settings for application 2.1.0 and database 3. Open Health → 戒烟. No reinstall or website-data clearing is needed.

Application 2.1.0 uses database/backup V3, adding three stores without rewriting the original nine. Old V0/V1/V2 backups are validated and migrated before atomic restore; restoring them intentionally replaces cessation collections with empty arrays and requires preview confirmation. Do not downgrade storage by deploying V2 assets. Back up important records once you begin using the app.

No license change, account/backend, analytics, personal-data attachment or generated build archive is introduced.
