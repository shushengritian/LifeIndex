# ADR-0014：Ocean 完整交付授权与分类 V4

状态：实施中，未发布。

用户本轮明确要求“直接把剩余的计划工作全部做完，部署上线”，覆盖既定 P5-01–07、GitHub 提交/推送与 Pages 发布。并非授权加入后台、账户、云同步或清空数据，也不自动豁免真机专项。

分类采用已批准 HLD/ADR-0012 的可选 parentId、同收支最多两级模型。数据库索引升级到 V4，旧分类仍根级；备份 V4 保留全部数据，V0–V3 在各自冻结 schema 后迁移。父级归档不改子级行，恢复父级不恢复独立归档子级。历史交易允许维持原有引用，创建/改选及 URL Action 必须使用有效分类。

V4 启用后，不部署只理解旧 schema 的回滚代码。发布前须完成分类 UI、旧数据与备份回归、其余设计计划、完整质量门槛与线上版本检查。没有足够证据时目标继续 active，不因一次构建成功宣称交付。
