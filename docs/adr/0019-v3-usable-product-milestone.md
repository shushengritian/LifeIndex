# ADR-0019 — 3.0.0 可用产品里程碑

2026-09-20，用户要求完成留白与专注显示优化后发布大版本 3.0.0。

3.0.0 是产品体验里程碑，不是架构重写或存储版本升级。延续已验收 Ocean 视觉与轻量本地优先范围。无账号、后端、付费服务或额外权限。

原弧线起点“0 分钟”是固定标尺，容易被理解为卡住的计时。改为明确的实时“已专注”时钟与独立目标时长；中央保持剩余时间。三个展示共同使用时间戳推导，不在后台累加回调次数；已完成汇总语义不变并明示。

专注操作与分隔线、历史入口调整留白，同步健康与记账相关区块。数据库/备份仍 V4，既有记录不改写。日志只含展示模式，避免每秒输出行为轨迹。

发布须通过静态、单元、双浏览器、子路径构建与线上检查。真机长按恢复导航与系统图标缓存仍是未确认事项，不借大版本宣布已解决。详见 [3.0.0 发布记录](../releases/v3.0.0.md)。
