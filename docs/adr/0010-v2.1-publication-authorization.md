# ADR-0010 — V2.1 直接发布授权与无数据备份豁免

**状态：** Accepted，2026-09-14。

用户明确要求“不需要备份，直接…发布更新，因为我本地没有任何数据需要备份”。据此 G2 发布许可通过；本次不要求导出空备份，不声称已存在新的 V2 备份，也不读取手机数据验证用户陈述。

授权包括将已实现的 V2.1 提交并正常部署到现有 GitHub Pages。保留所有静态、数据迁移、浏览器与线上验证门槛，不清空 IndexedDB、不降级协议、不更改仓库可见性或权限。

直接发布指令允许先上线再由用户验证手机，本次真实 iPhone 验证列为发布后待确认；没有声称真机通过，也不将 ADR-0008 的 V2 例外自动沿用。后续有数据时仍建议先备份；本次豁免不能推广为所有升级都无需备份。
