# ADR-0018 — Ocean 图标扩充与设置交互加固

日期：2026-09-20。状态：用户已授权发布 2.2.2，再做手机复验。

## 范围与决策

1. App 图标改为原创几何 Ocean L/索引标记，提供 SVG 源与可重复生成的五种 PNG，不增加依赖。
2. 分类图标从 42 扩为 60，新增旅游住宿、家庭教育、生活服务三组，总计 11 组。二级分类仍仅名称，不恢复图标编辑。
3. 设置行、外观选项的交互高亮统一 14px 圆角，保留直线分隔符与键盘焦点；只对应用导航/设置行禁止链接长按预览，不禁用正文选择。
4. Sheet/ConfirmDialog 关闭还原焦点时使用 preventScroll，避免额外滚动；不强制刷新页面、不清数据、不把所有背景一律解除 inert。

## 数据兼容

数据库/备份仍为 V4：没有字段、表、索引或既有记录迁移，图标是现有字符串字段的允许值增量。V0–V3 的冻结图标规则保持不变；旧 V4 备份可以继续导入。扩充后所有图标经过导出→预检→恢复→数据相等的集成测试。

这不是向旧程序双向兼容：2.2.0/2.2.1 的严格枚举会拒绝包含新图标的 V4 备份。新图标启用后应使用本次或更新的程序恢复，不能降级旧代码。不得把新图标静默改成旧值以绕过校验。未来若改变数据结构或字段语义，仍需单独的版本迁移。

## 导航消失：证据边界

用户补充路径：长按“从备份恢复”弹出框，上下拖动后点击其他空白处，导航栏下移并消失。该入口是内部链接，现有证据更符合系统链接预览及视口恢复问题，尚未确认浏览器内部根因。静态检查未发现取消分支主动隐藏底栏。当前限制该入口的长按预览并加固焦点恢复，不宣称已确认真机根因。

回归覆盖模拟 contextmenu、空文件选择/cancel 事件、嵌套确认框取消与放弃、背景 inert 恢复、五项导航可见且可点击。浏览器自动化不代表实际 iOS 原生系统窗口或硬件键盘行为；系统长按/文件窗口取消仍需手机复验。
