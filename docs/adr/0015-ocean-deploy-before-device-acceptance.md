# ADR-0015：先部署 Ocean，再进行 iPhone 验收

日期：2026-09-20。状态：用户已批准，执行中。

用户询问是否可以不在 Mac 测试、先部署再手机验证，并在明确说明该顺序后回复“继续吧”。本决定替代 ADR-0014/G5 中将原生与手机验收作为本次 App 发布前置的要求；不删除待验收项，也不将其记作通过。

1. 发布 App 2.2.0，保留静态检查、234 项单元/集成、完整 Chromium/WebKit 回归、Pages 配置路径构建及真实线上 smoke 门槛。
2. Mac 原生快捷安装不再是前置，不安装或运行本机快捷指令。
3. 原生截图记账候选仍属未验证测试产物。当前 App 保留分类导出与草稿接收，安装入口继续明确“暂未开放”；手机测试模板交付/安装、OCR/分类/同账本验证作为后续工作，不冒称已完成。
4. 发布后在 iPhone 检查界面、键盘、安全区、离线、专注后台恢复、VoiceOver/放大及截图记账流程。用户提供 iOS 版本和日常入口后协作执行。
5. 数据库与备份升级至 V4，迁移回归保留。更新不清除数据；V4 设备不能回滚至仅理解 V3 的旧客户端。

App 部署成功、快捷指令测试交付、真机最终验收是三个独立状态。此决定不增加后端、账户、云 OCR 或同步，不自动完成长期目标。
