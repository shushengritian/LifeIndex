# ADR-0017 · 精简外壳与记账入口

2026-09-20，用户明确要求删除顶部本机状态徽标与外部记账功能的全部计划和实现。

## 决定与范围

- 顶部只显示页面上下文；本地存储风险说明仍保留在设置的数据与安全页。
- 删除外部记账说明、安装引导、分类配置导出、原生模板构建/签名/OCR 脚本及其专用测试。
- 删除外部交易草稿编辑器及 URL 新增交易解析/执行路径；旧链接拒绝且清理参数，不写入任何业务数据。
- 文档、原型、验收计划同步收敛，不将撤销功能保留为后续待办。
- 今天“记一笔”、正常交易表单、二级分类、备份、健康与专注不变；既有习惯/专注链接操作保留。

## 数据兼容

数据库与备份继续 V4，不删除表、不改写真实记录。历史动作回执类型只用于旧库/旧备份验证、恢复与引用清理，不开放对应运行入口。运行类型与持久化兼容类型分离；解析层与服务层都拒绝已撤销操作。

## 验证与发布

检查旧入口重定向、无写入、无敏感参数日志/网络传输、现有备份与迁移以及双主题布局。Impeccable 仅手动参考，保留必要存储说明，不运行引擎。本批为本地修改，发布须另行执行正常版本和 Pages 门槛。
