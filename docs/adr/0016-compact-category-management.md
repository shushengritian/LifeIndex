# ADR-0016：紧凑分类列表与纯文字二级分类

2026-09-20，用户提供两张记账应用截图，要求参考其分类管理，二级分类不需要图标，并指出大按钮过于粗糙。本变更覆盖此前二级分类需选择图标的交互约定，不改变两级结构或账目引用。

- 一级分类保留彩色图标与名称，整行进入二级列表；新增使用 44px 点击区域内的小加号。
- 三点“更多”收纳编辑、二级分类、上移/下移和归档；不再每行铺开大按钮。保留支出/收入/专注/运动切换和默认折叠的分类入口。
- 二级分类列表和记账选择器使用纯文字标签；新建/编辑只要求名称。上下移动仍在更多菜单中，没有实现或暗示拖拽、复制、重置与物理删除。
- 新二级分类在存储中沿用父级 icon/color；编辑旧二级分类保留原 icon/color，仅 UI 隐藏其设置。V4 仍要求这些字段，因此不删除字段、不迁移、不改备份版本，也不重写既有数据。
- 归档而非永久删除仍是数据安全契约；归档确认、失败重试和历史账目保留不变。

状态：本地实现与自动化验证完成（235 项单元/集成、67 项浏览器通过、1 原有跳过），未包含在已部署的 2.2.0 中。产品仍使用 Ocean 深浅主题，不复制截图中的黄色主色。
