# ADR-0001：当前版本产品范围与本地数据契约

日期：2026-09-21。状态：范围已确认，发布验证待确认。

## 决策

公开版本名为「3.3.0」，内部包版本为 `3.3.0`。产品提供今天、健康（体重、运动、习惯）、专注、记账、设置。

采用静态 React/TypeScript PWA、Hash 路由、Dexie 和 IndexedDB。业务数据在本机，Service Worker 仅缓存应用外壳。备份由用户主动导出和恢复，不引入账户、后端或云数据库。

数据库版本 5 使用当前九表定义；升级以当前表集合识别结构，在事务中保持有效数据和索引，只接受当前设置键。升级测试使用原生版本 40 到 50 的合成数据。

备份导出 V5。导入支持 V0、V1、V2、V5；V0→V1→V2 使用确定性的内存规范化，再校验为当前数据。其他格式拒绝且不写库。预览确认后，九表在一个事务内替换；任何失败回滚。

## 理由与影响

单一当前范围使需求、UI、存储、备份与验收保持一致。应用版本、数据库版本和备份版本分别管理。数据安全优先，源码回滚不能代替数据库降级方案。

真机专项须有用户确认。当前实施与发布证据记录于 [计划](../../PLAN.md)和[发布记录](../releases/v3.3.0.md)，本决策不声明测试或部署完成。
