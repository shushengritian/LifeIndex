# ADR-0020：操作体验设计进入生产开发

日期：2026-09-20。状态：用户授权本地开发；发布待另行授权。

## 决策与依据

用户在两轮设计审核和 OPEN-01 定点收尾后明确要求「开始开发工作」。以 [收尾设计](../design/operation-refresh/DESIGN.md)作为实施依据，不再把设计验收作为开发阻塞，也不把该授权解释为部署或版本更新许可。

保留 React、现有领域函数/仓储、IndexedDB/V4、备份 V4、Ocean 双主题和五导航。原型的合成数组、模拟延迟、文件操作和整页重绘不迁入生产。

## 首批范围

先落实共用编辑容器在记账中的接入，以及记账闭环和轻量报表。表单头尾固定、中部滚动；危险操作移至详情并保留确认/失败重试。报表作为 `/finance/report` 子页，仅聚合已有账目，类别用横向条形图、日期用折线；替换主页折叠分类/六个月统计，主页日历与七日支出保留。零记录空态不画假曲线。

报表打开期间父记账页保持挂载但隐藏，保留日历日期和滚动返回上下文；浏览器返回与页内返回使用同一父页，不增加持久化缓存。直达报表时缺少来源上下文，返回当前日的记账页。报表月份参数只用于展示，不接受写入。

## 边界与后果

每批单独同步契约和测试。新共享容器逐模块接入，未接入模块不宣称已重设计。保留现有数据写入锁、草稿导航保护和 PWA 更新协调；新 UI 不新增写路径。生产实现不得直接继承原型测试结论，真机专项仍未测。

后续顺序与状态见 [实施计划](../development/OPERATION_REFRESH_DEV.md)。本次不更改应用版本、不提交推送、不部署。
