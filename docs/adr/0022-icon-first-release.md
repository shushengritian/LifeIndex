# ADR-0022 — 图标化操作 R1.1 实施与发布

日期：2026-09-21。状态：用户明确授权「开始开发和部署」。

## 决策

以 docs/design/icon-first/BRIEF.md 的 R1.1 交互契约为本次实施依据，发布版本3.2.0。保留 Ocean 双主题、既有五入口和数据/备份V4。

- 今日摘要单列，查看内容与标题写入分离；习惯名称与打卡为独立同级触点。
- 健康内容进入真实历史/详情；戒烟无计划整卡创建，有计划查看和记录分离。
- 记账页头仅新增，报表独立内容行；编辑器关闭/标题/图标保存。
- 专注完整360°轨道，准备与计时场景分离，收起不结束；保存中、失败、重试及明确放弃保留真实持久化契约。

原型中的静态日期、固定汇总、内存写入、详情占位不是生产规范，不得覆盖正式业务。未展开的保存状态沿用并验证现有安全逻辑，不以原型假成功代替。

## 门槛与边界

类型、lint、单元/集成、生产构建、Chromium/WebKit回归与线上检查后记录实际结果。视觉验证针对几何、入口分离和留白，不用测试数量代替截图核对。系统长按菜单、软键盘、主屏幕更新及真实后台行为留给用户iPhone复验，未测不记为通过。
