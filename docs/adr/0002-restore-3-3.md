# ADR 0002：撤回4.0，恢复3.3.0

日期：2026-09-29。状态：用户明确批准。

用户否决4.0视觉体验并要求“直接回退并部署，4.0不保留”。当前产品恢复为升级前3.3.0 Ocean，以48cf37a的应用、资源、依赖与发布流程为准（应用代码与原已部署388c077一致）。撤回4.0实现及其专属设计、测试和交付文档，不提供双版本入口。

采用普通撤回提交，不强推或改写Git历史。只恢复旧版源码，不新增业务逻辑，不引入数据删除脚本；已有核心注释及隐私日志随原实现恢复。部署不能恢复用户已清除的数据，也不将4.0数据库或备份转换为3.3格式。用户表示真机无须保留数据，但客户端存储仍由用户设备管理，不通过应用启动偷偷删库。

重新执行3.3质量检查、浏览器回归、Pages部署和实际线上验证；保留原测试明确标识的WebKit离线整页重载限制，不将跳过记为通过。真机仍待用户确认。结果见发布记录与PLAN。

## 后续修订：保留设计参考

用户随后要求保留4.0相关设计文档供借鉴，代码仍删除。已恢复[设计参考档案](../design/v4/README.md)及静态截图/观察记录；不恢复任何4.0生产代码或可运行原型。此前移除设计资料的决定由本修订替代，3.3.0产品范围及部署不变。
