# ADR-0011：体验重设计范围与审核边界

日期：2026-09-15；2026-09-19 更新。状态：G1–G4 用户审核已通过；生产实现授权与 G5 发布许可尚待确认，未完成工程验证不自动豁免。

最新授权（覆盖上方历史状态）：用户明确“开始第5阶段”并要求“继续”，允许生成开发规格和修改正式代码。已进入本地实施；G5 推送/发布未授权。G4 遗留工程专项继续验证，不视为豁免。

## 背景与授权

用户要求先审计再分阶段重设计；收到 G1 交付与明确审核请求后回复“确认”。该批准覆盖：保留五导航和业务/schema，完善未保存输入保护、健康完整历史入口、统一交互，按 MOZE 信息层级 + Things 简洁感做双主题设计。

## 决策

进入 G2 信息架构、核心流程、状态/文案与隔离低保真。G2 用户批准后才进入 G3 视觉定稿；G4 完整原型批准且有明确实现授权后才改生产代码；G5 另行申请发布。健康新增历史入口只扩展数据访问界面，不改变存储和统计。

不新增后台、账号、云端服务、暂停计时、自动习惯联动、医疗算法或 schema。没有创建新长期 Goal。旧备份豁免和发布授权不沿用。设计稿只使用合成内存数据，不访问真实库。

## 影响与替代

相比仅改样式，本范围可解决任务闭环问题，需先验证导航与退出协议。替代的“只做视觉”不能处理已发现草稿/历史问题，因此未选用。框架如何拦截浏览器返回及系统终止限制留实施规格验证，不承诺浏览器做不到的保护。

本 ADR 不冻结 G2 具体页面样式，也不授权推送、部署或生产实现。当前跟踪见 [重设计计划](../project/REDESIGN_PLAN.md)。
