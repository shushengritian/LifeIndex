# LifeIndex 4.0 使用与范围

状态：4.0.0已部署，线上独立验收8项通过。它是全新设计，不读取、迁移或清空旧版数据库；新版业务使用独立 LifeIndexV4，旧版备份不能导入新版。

## 日常任务

- 今天：查看当天计划、完成进度、专注入口、收支摘要和真实轨迹。习惯整行是完成/撤销动作，旁边“详情”只打开计划；没有勾选图标或加号悬浮按钮。
- 留一笔：底栏中央或桌面侧栏的笔形入口，选择记账、体重或运动后立即编辑。全局默认今天，日期始终可见；显式某一天的录入继承所选日期。保存回原位置并提供真实日期及“查看记录”。
- 健康：记录整数克精度的体重、整数分钟运动；查看历史、编辑和确认删除。习惯支持名称、图标、每周计划、暂停及历史补记，暂停不删除已完成事实。
- 专注：15/25/45分钟，默认25；开始、暂停、继续、收起、提前结束和放弃各有明确动作。未结束状态持久化，暂停不计时；保存失败保留固定终点并可重试，少于一秒不能保存为空会话。历史仅汇总完成记录，可编辑名称/分类/备注。
- 记账：收入/支出、金额、分类、日期和备注；日历和列表按同一日期范围浏览，月报可追溯分类与明细，返回保留原范围。
- 设置：系统/浅色/深色外观，四领域扁平分类的创建、编辑、排序、归档/启用和未引用删除；备份恢复及数据安全说明。

记录查看不写入。编辑失败保留输入；离开脏草稿需确认。其他标签删除记录或恢复数据后，旧草稿仍可读取和复制，提交会安全拒绝陈旧身份，而非覆盖新数据。

## 数据语义

金额采用CNY整数分；体重采用整数克，界面以kg输入；运动是1–1440整数分钟。交易、体重、运动只记录日期，不伪造具体发生分钟。专注与当天习惯的真实时刻使用捕获的时区offset，历史补记习惯只有日期。专注跨午夜归入开始日，详情保留真实起止日期。

新版分类为一个层级，19个默认分类仅在新库初始化时创建，不恢复用户删除的未用分类。归档保留已有引用。数据库、应用版本和备份版本分别管理，当前为schema1、4.0.0、备份formatVersion1。

## 备份与离线

设置→备份与恢复导出完整八类数据，文件交给浏览器后须自行确认已保存。导入只接受新版JSON，最大50MiB；完整校验后显示源/本机数量及未结束专注，15分钟内再次确认才原子替换。预览后本机有新写入则要求重新检查；任何事务失败保留替换前的数据。取消或重选不会让旧文件的迟到结果重新出现。

首次联网完成外壳缓存后支持离线打开、记录和回看。没有账号、云同步、分析追踪、业务后端或远程字体。浏览器清站点数据可能永久删除本机记录；更新不要卸载或清库。运行环境仍可能回收存储，应定期保管备份。

本次不交付3.x动作链接、两级分类、历史迁移或旧备份兼容。旧代码仅供历史回归，不从新版入口加载。市场“前20%”是品质愿景，没有将内部评分包装成市场排名。
