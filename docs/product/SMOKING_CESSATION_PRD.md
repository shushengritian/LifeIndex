# 戒烟模块 PRD — V2.1 提案 0.1

**状态：** 2026-09-14 用户批准实现；本地 V2.1 规格，尚未上线。技术细化以 [CESSATION_V3](../architecture/CESSATION_V3.md) 为准：起点/基线创建后固定、原因可编辑、计划日历固定时区；必须先结束旧计划再新建。
**位置：** 健康 → 戒烟。目标为单人本地行为记录与轻量支持，不是医疗诊断/治疗工具。

## 2. 用户任务与范围

我想知道自己从何时开始、哪些天确实没抽、想抽时能做什么，以及偶尔抽了之后如何继续，而不是管理一个复杂戒烟项目。

P0：一个计划、每天一条状态、一次烟瘾帮助/记录、吸烟事件、轻量日历、可选节省估算、计划结束/重启与本地完整备份。

不含：AI 医生、社交排名、自动吸烟检测、自动推送、电子烟口数换算、药物、复杂问卷、医学恢复进度、品牌/烟草 SKU、地图、用户账号、云端或跨模块自动写入。

首版烟量与价格估算仅用于纸烟（支/包）；也允许不填基线、只使用记录与支持。其他烟草/尼古丁产品不做等价换算；不暗示电子烟安全或提供替代建议。

## 3. 功能与验收

| ID | 需求 | 可验证行为 |
| --- | --- | --- |
| SQ-01 | 健康内可选入口 | 初次为一行“戒烟 · 开始计划”，可隐藏；健康右上角 + 提供重新打开入口。活跃计划为紧凑卡片，详情不增加底部项 |
| SQ-02 | 开始计划 | 必填开始日期时间，默认现在；允许过去，未来最多 30 天（产品范围限制）。可选原因 ≤80 字；可选原日均 1–100 支、每包 1–100 支、每包 CNY 价格 0.01–9999.99。估算字段可全不填；若开始填写须完整有效 |
| SQ-03 | 计划状态 | 未到时间显示“准备开始”，不显示成功时长/无烟天数；时间到后按时间投影为进行中。最多一个未结束计划，关闭或重新开始需确认，历史保留 |
| SQ-04 | 今日状态 | “截至现在未吸烟”是一键幂等快照，不代表未来剩余时间；允许撤销。跨日后没有覆盖完整一天的确认仍显示待确认，不自动变成无烟日 |
| SQ-05 | 补充日确认 | 点击已过去日期，可确认“全天未吸烟”；当天有吸烟事件则禁止该确认并提示编辑相关事件。未来日期禁用；计划开始的非完整日可记录但不计完整日统计 |
| SQ-06 | 想抽烟时 | 点“我想抽烟”打开短时帮助；可选诱因（饭后/压力/社交/无聊/其他/不填写），不填也可继续。可开始 3 分钟、随时结束或跳过；结束选“缓解了”“还想抽”，仅明确保存才记录事件，不自动完成打卡 |
| SQ-07 | 记录吸烟 | 次要但明确的“记录吸烟”入口；默认 1 支与现在，可改次数/日期时间/可选诱因；1–100 支/次，不能晚于现在或落在计划范围外。保存后提示“已记录，之前的努力仍保留”，不自动结束计划 |
| SQ-08 | 冲突与更正 | 保存吸烟事件时在同一事务中撤销同日无烟确认；删除/移动事件后不自动补回确认。事件可编辑/确认删除；撤销误记后指标从事实重新计算 |
| SQ-09 | 回顾 | 详情内近 7 天概览 → 月历；日期可点。显示完整无烟日数、记录覆盖数/可记录日数、诱因分布仅计已选诱因。不加排行榜/年度热力图；空数据不画假趋势 |
| SQ-10 | 估算节省 | 仅在基线完整且已有完整无烟日时展示；未记录、当日快照、部分日、有吸烟记录日不纳入。显示“估算”，说明口径；不写入记账的收入、支出或结余 |
| SQ-11 | 支持 | 详情底部静态帮助，说明“微信搜索：中国戒烟平台”，链接 WHO 官方资源；打开前明示离开 App、需要网络、不携带个人记录。电话与深链未核验前不硬编码 |
| SQ-12 | 保留与隐私 | 所有个人数据仅 IndexedDB，离线可写；纳入全量备份/校验/原子恢复；不进入 URL、日志、报告或仓库。隐藏入口≠删除；结束计划≠戒烟成功认证 |

## 4. 数值与时间口径（审核重点）

- 主数字默认“距戒烟开始”：当前时刻减开始时刻；有吸烟事件则改为“距最近一次已记录吸烟”，取本计划最后一条吸烟事件的时间。不叫“医学确认无烟时长”，始终附“根据你的记录计算”。没有日志不能证明持续未吸烟。
- 完整无烟日：已过去、完整落在本计划起止范围、用户明确确认且没有吸烟事件的本地日。开始于 09:00 的首日、结束于 18:00 的末日不计；当日计时不计整日。
- 日状态优先级：有吸烟事件 > 完整无烟确认 > 当日截至现在快照 > 未确认/未记录；烟瘾事件不改变该状态。
- 过去的快照显示“待确认”，而不是无烟，也不是失败；过去无记录显示“未记录”。允许补记和撤销，统计立即重算。
- 估算少吸支数 = 完整无烟日数 × 计划基线日均支数；估算节省分 = 四舍五入（少吸支数 × 每包价格分 ÷ 每包支数），整次汇总后舍入。不是已实现现金节省，不是全时段净减少量。
- 例如已确认 8 个完整日、原 10 支/日、20 支/包、30 元/包：约少吸 80 支、估算 120 元。未知的 4 天不计算；吸烟事件不扣已确认的其他天。
- UTC 时刻用于时长；日期按计划不可变 IANA 时区分组。已存日期不随旅行重新归组，记录不得跨计划；CESSATION_V3 冻结夏令时边界算法，不能把所有一天当成 24 小时。
- 原日均与价格是单个计划的估算基线；创建即冻结，历史计划不被新价格重算。开始时间也固定；需要新的起点时明确结束并新建，不静默移动历史。

## 5. 状态与文案

加载中：占位，不显示 0 天。读取失败：“记录暂时无法读取，重试”，不展示旧值为新值。保存失败：“未能保存，输入已保留”，按钮恢复可点；处理中禁止重复提交。离线：记录正常保存，外链解释需要网络。

吸烟后不出现“失败”“清零”“破功”。关闭计划保留历史；重新开始必须先明确结束旧计划，再填写新计划开始时间。已结束详情停止今日快捷记录，允许更正历史事件/日确认但不得越过原范围。删除整个戒烟历史不提供独立捷径，本版沿用全局数据安全规则。

支持页注明：“LifeIndex 提供自我记录与一般支持，不替代专业诊疗。戒烟困难或不适持续时，请向专业人员寻求帮助。”不提供症状诊断或自动就医分级，不推荐以本功能替代正规治疗。

## 6. 与已上线模块的关系

- 体重/运动/习惯结构和已有数据不变；不自动创建“戒烟习惯”，避免两套连续天数互相矛盾。
- Today 本版不增加新卡片；不因健康增加一项而重新设计全站。
- 戒烟短休息独立于 Focus，不生成专注时长，不打断现有专注会话。
- Settings 保留四个独立组；戒烟导入/导出纳入“数据与安全”已有全量备份，无新数据中心。
- 所有样例数字与日期均为合成演示，不读取用户健康记录。
