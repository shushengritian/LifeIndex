# LifeIndex 当前版本需求

公开版本：3.3.0。范围依据：[产品基线](../../LifeIndex-Project-Baseline.md)。

| 模块 | 用户操作与结果 |
| --- | --- |
| 今天 | 查看当日收支、已保存专注及习惯状态；进入记录表单或详情 |
| 体重 | 记录体重、测量时间及可选备注；查看趋势和历史；设置目标 |
| 运动 | 记录分类、时长、强度、时间及备注；查看和编辑历史 |
| 习惯 | 新建和管理日常/指定星期计划，暂停/启用，按本地日期打卡与查看日历 |
| 专注 | 选择时长和事项，开始计时，完成或提前结束并保存，查看历史 |
| 记账 | 记录收入或支出、金额、分类、时间和备注；按日历浏览和编辑流水 |
| 报表 | 按月份和收支类型聚合分类与每日趋势，空月份展示空态 |
| 设置 | 管理分类与外观，导出 JSON，预览并确认恢复，查看版本与数据安全提示 |

## 交互规则

查看详情与记录操作使用独立入口。今天打卡与习惯名称点击分开；保存后重新读取本地状态。异日账目提供回看记录日期的入口；报表返回保持流水浏览上下文。

专注最多一个进行中会话，计时以时间戳计算，前后台切换后重新计算；实时已用、剩余和目标分别表达。待保存状态不进入历史汇总；保存失败保留输入和会话上下文。

记账分类支持两级结构、排序和归档，历史引用保持可读；健康记录和习惯提供可回看的明细。编辑离开保护草稿，提交期间防重复，持久化失败允许重试。危险操作明确确认。

## 数据与验收

用户在相同来源下离线记录，刷新及重新打开后仍可读取。备份先验证再预览，确认后原子恢复；无效输入不改库。导入支持 V0、V1、V2、V5，详见 [备份契约](../architecture/BACKUP_SCHEMA.md)。

需覆盖深浅主题、320–430 CSS 像素、键盘与读屏、空态/加载/失败、焦点返回、系统文件取消、后台专注和更新保护。验收状态见 [测试计划](../testing/TEST_PLAN.md)。
