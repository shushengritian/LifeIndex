## 1. 产品目标与非目标

面向在 iPhone 上记录金钱、专注与健康的个人用户，让高频记录容易开始、结果可确认、历史可回顾、异常可恢复。成熟度来自完成任务的可靠性，不来自更多功能。当前使用频率和偏好仅有用户交流，未做访谈/可用性研究，不虚构人群占比。

保留今天、记账、专注、健康、设置五项导航。MOZE 信息层级 + Things 简洁操作秩序是方向，不是已完成竞品研究或品牌复制许可。后续竞品取证须记录页面来源、日期、借鉴点和不采用点。

不新增：账号、后台、云同步、遥测、社区、AI、复杂训练/饮食处方、暂停计时、自动支付识别或新的时间线业务。本轮不改生产代码，不引入依赖，不发布。禁止使用 localStorage 保存核心业务数据。

## 2. 数据与业务不变量

- IndexedDB 主库；SW 只缓存应用壳。保留现有逻辑 schema 3 和 Backup V3 的 12 stores：categories、transactions、habits、habitRecords、focusSessions、settings、actionReceipts、weightEntries、activitySessions、cessationPlans、cessationDays、cessationEvents。
- 金额使用整数最小货币单位；日期、时区和现有汇总算法不因排版变化修改。
- 运动记录不会自动打卡习惯。习惯撤销不得影响其他健康记录。
- 专注现有开始、到期、提前结束、取消模型保留；后台恢复依据绝对结束时刻，不以界面动画时间替代事实。
- 戒烟计划经过时间不是连续无烟天数。当日快照不是全天确认；未记录不是无烟；吸烟会使对应确认失效，删吸烟记录不自动恢复确认。计划时区、结束、隐藏和历史语义按 `../architecture/CESSATION_V3.md` 保留。
- 恢复是整库替换，不是合并；完整解析、校验和预览后才允许原子替换。不可用“撤销”假承诺恢复已不可逆的数据。
- 不新增 schema；若实施发现必须迁移，停止该变更，提交字段/兼容/迁移/回退影响与替代方案，获得独立批准。

## 4. 体验契约（G2 细化，G3 定稿视觉）

短新增/编辑优先底部表单；动作选择使用操作面板；长历史独立页；成功用非阻断反馈，保存失败在表单内；危险操作明确动作名称，不用含糊“确定”统一代替。表单必填项清楚，数值/日期使用适合的输入方式；不以自制选择器牺牲系统键盘的可用性。

统一状态：默认 → 编辑 → 校验失败（保留）/保存中 → 成功（更新视图并返回来源）/失败（保留并可重试）。取消区分干净退出与放弃更改；不可逆动作取消不能写入。保存期间是否允许离开须由操作契约统一，不让组件自行决定。

按钮不是全部图标化：主操作可图标 + 文字；通用新增/关闭等图标有可访问名称；“开始计划”等不够通用的概念保留清楚文案。危险操作不和日常操作争夺视觉焦点。优先一致图标家族，新增资源先登记来源和许可证。

设计验收目标：正文/标签清晰可读，关键触点目标至少 44×44 CSS px；密集日历等若需要例外须记录间距/替代入口和评估。正常文本对比度目标 4.5:1、大文本与必要非文本界面 3:1。200% 放大/长文本不得遮住关键动作；目标值不是现有实现已达标声明，G3/G4 需测量。

## 5. 成功标准与测量方法

1. 在相同合成任务下记录入口点击、选择、输入项、确认、回退与滚动；当前基线见审计，不编造效率百分比。G2 目标先消除今天记账的重复入口，不为减少步数取消必要风险确认。
2. 每个 CRUD 和高风险动作都有成功、失败、忙碌、取消证据；连续操作不产生重复业务结果。
3. 设计覆盖清单关键状态无空白；静态稿和原型标清未实现动作。
4. 数据/计时/戒烟语义回归与旧备份兼容通过；无 P0/P1 遗留方可推荐发布，其他缺陷列明处置。
5. 自动化绿色、视觉验收、用户设计批准和 iPhone 验证是不同条件，分别记录。不能自动将无法完成项记为通过。

## 6. G1 需确认的范围

推荐一次确认：保留五导航与现有业务、schema 不变；纳入完整健康历史入口及跨模块退出/风险动作统一；接受先交互后视觉、G4 后另行授权实现。替代方案是仅做视觉翻新，但不会解决草稿丢失与旧记录入口问题，因此不推荐。

若无特别偏好，先采用健康摘要 + 独立历史方向做 G2 低保真；具体底部表单尺寸、字号、配色、图标和导航细节不在 G1 锁死。开发与发布权限仍需后续独立确认。
