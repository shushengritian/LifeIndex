# 戒烟实现契约 — V2.1 / schema & backup V3

2026-09-14：用户明确要求“开始代码的实现和文档修改”，G1 通过。本契约冻结已批准设计的技术细节；发布仍受 V2.1 G2 控制。

## HLD 与 LLD

健康卡片 → `/health/cessation` → CessationRepository → IndexedDB。纯日期/统计/完整性规则位于 `src/shared/domain/cessation.ts`，Zod 边界在 `cessationSchemas.ts`；备份复用同一完整性验证。无网络数据服务、药物或其他模块自动写入。

数据库保留 V1/V2 的九张表和声明；V3 新增 cessationPlans (`id,startAt`)、cessationDays (`id,&[planId+localDate],planId,localDate`)、cessationEvents (`id,[planId+localDate],[planId+occurredAt],planId`)。类型定义以 `src/shared/domain/types.ts` 为准，事件用 smoking/count 与 craving/outcome 判别联合，禁止不适用字段。隐藏入口保存在类型化 cessationHidden 设置。

计划保存不可变 IANA timeZone，默认设备当前时区。开始时间由原生时间输入转换为 UTC；所有戒烟日期按计划时区分组，UI 显示该时区。日期不随旅行重新归组。利用 Intl 将 UTC 映射到计划日期，再二分定位日边界；不能用固定 24 小时估算夏令时完整日。新字段替代提案中的冗余 offset 字段，不改变其他模块日期语义。

日确认：snapshot 是 reportedAt 当日、开始后、结束前的快照；跨日只显示待确认。fullDay 必须在 reportedAt 前结束、完整落在计划范围内；吸烟事件与同日确认不得并存。保存/移动吸烟事务撤销目的日期确认；旧日期与删除后都不自动创建确认。

计划时间区间不重叠，最多一个未结束计划。记录的时刻可等于计划终点，避免同毫秒结束造成事实丢失；日统计依然按完整日范围。未来计划取消保存 startAt=endAt 的空区间，无记录，显示已取消，不改写计划起点。正在进行/准备中由当前时刻派生；结束仅停止记录，不声明医学成功。

开始命令/事件创建使用稳定 UUID；同 ID 重试幂等。所有写操作都在三表读写事务中执行，并在提交前校验全域不变量；失败回滚并发出只包含操作类别的日志。计划原因可编辑，起点与基线在本版固定；调整起点走明确结束/新建，所有旧事实保留。

## 备份

BackupService 输出格式 V3，完整快照/恢复事务覆盖 12 张表；恢复必须先预览并校验、再一次性替换。V0→V1→V2→V3 逐级使用冻结的格式边界，V2 的三张新表只填空集合。V1/V2 不接受 cessationHidden 这种未来设置。

校验包括各表 UUID 唯一、同计划同日期唯一、引用存在、无多活跃/重叠计划、事件时间和计划日期匹配、日确认完整性及吸烟互斥。日期事实按备份 exportedAt 校验，长期有效备份不会因为导入设备时区变化而失效。

恢复旧备份会用空戒烟集合替换当前戒烟历史，预览必须明确提示。不得靠降级部署旧 V2 代码来降级 V3 数据；保留原备份并使用经过验证的恢复协议。

## 统计与隐私

时长使用 UTC 起点/最后一条吸烟到当前或结束时刻。未知日期不计完整日；收益只按确认完整无烟日 × 原日均支数 × 每包价格分 / 每包支数，汇总后舍入一次；无基线不显示。覆盖率为有日确认或事件的日期数 / 计划已到达日期数（包含部分日），未到开始/取消计划分母为零；诱因只统计显式选择的事件。事件/原因/数量/日期/价格/时长/原始异常信息不写日志或 URL。注释解释事务和状态边界，UI 失败保留表单并使用同一操作 ID 重试，Escape 与取消使用同一草稿确认规则。
