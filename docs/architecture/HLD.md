# LifeIndex 总体架构

当前版本为单人使用的静态 PWA。React/TypeScript 管理界面，Vite 构建，Hash 路由承载页面，Dexie 封装 IndexedDB。无业务服务器或账号系统。

## 分层职责

| 层 | 职责 |
| --- | --- |
| app | 服务注入、路由、外壳、导航保护、错误边界和链接确认 |
| features | 今天、健康、习惯、专注、记账、设置及只读聚合 |
| shared | 领域类型、校验、金额/日期规则、安全日志、共用 UI |
| data | 数据库与升级、仓储、备份校验、预览及原子恢复 |
| pwa / sw | 外壳缓存、离线状态、更新发现和用户确认激活 |

UI 调用仓储并在提交成功后刷新查询；IndexedDB 是唯一持久化主数据源。表单草稿与备份预览 token 只保存在内存，不形成第二套业务数据库。

## 一致性

业务约束在校验和仓储边界执行。关联写入、链接业务记录与回执、备份恢复均采用事务。聚合由现有记录计算，不另建报表数据源。

数据库版本 5、备份格式 V5 与应用包版本相互独立。结构及升级见 [数据模型](DATA_MODEL.md)，恢复见 [备份契约](BACKUP_SCHEMA.md)。

## 离线与隐私

Service Worker 缓存应用外壳，不缓存用户记录、备份或链接内容。更新激活须保护未保存输入与活跃操作。静态 HTTPS 托管支持项目子路径，来源变化不会自动搬迁 IndexedDB。

日志只记录操作名、状态、版本、计数与安全失败分类，不包含金额、标题、备注或备份正文。真机持久化、系统文件和安装更新需要独立设备证据。
