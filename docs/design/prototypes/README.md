# 隔离设计原型

`g4-review.html`：2026-09-19 当前 G4 A–C/D1 双主题审稿板。`g4-app.html` 及配套脚本为五导航内存原型，复用已批准的 `g3-ocean.css`；备份仅风险流程演示，不读写文件。`g4-states.html` 为离线/更新独立交互模拟，不注册 SW、不接受外部 Action 参数、不执行真实操作。D2 完整验收尚待完成，覆盖及待办见 [G4 进度](../G4_PROGRESS.md)。旧 G3 稿保留。

`g3-ocean.html`：当前 G3 R4 审稿，记账/健康/专注、六个独立双主题窗口。`g3-ocean-app.html` 和配套 CSS/JS 是可点击内存样板；规则、证据和未覆盖项见 [R4 审稿](../G3_OCEAN_REVIEW.md)。不能直接作为生产实现。

`g3-visual.html`：G3 双主题高保真样板，覆盖记账/健康/新增记录；可切换深浅、密度、首页/表单状态。见 [视觉系统](../G3_DESIGN_SYSTEM.md) 和 [G3 审稿](../G3_REVIEW.md)。不执行真实存储，不是全应用原型；直接打开或使用同一本地服务器预览。

`g2-lowfi.html`：G2 灰阶交互审稿，说明与验证见 [G2_REVIEW](../G2_REVIEW.md)。这是设计交付，不是生产页面；不可用演示逻辑替换仓储或领域规则。

- 用浏览器直接打开即可；如需本地服务，从仓库根目录运行 `python3 -m http.server 4176 --bind 127.0.0.1 --directory docs/design/prototypes`。
- 使用合成内存数据，不访问业务库、不持久化、不联网。刷新重置。
- 勾选审稿区“下一次保存模拟失败”，再提交表单可检查保留输入与重试。
- 固定金额/日期/热力图是布局示例；静态能力均明确标注。不可当成产品数据和实际统计结果。
- 关键分支有注释及固定事件日志，不记录用户输入。无新依赖，不需要构建，不属于 Pages 发布物。
