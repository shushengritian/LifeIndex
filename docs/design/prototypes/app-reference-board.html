A · Tide Guide

数据优先 · 深色仪表

Apple Design Awards 2026 · 视觉与图像获奖

美区 App Store：4.7 / 约 9,900 条（总分满分 5；评分不是 UI 专项评分）

看哪里

日期是骨架，曲线是主角，图标与数值形成紧凑的辅助层。底部导航与内容分离，但没有把每个数值都装进大卡片。

我建议借鉴什么

记账的日历与每日收支层级；健康的体重趋势。学信息密度与图表标注，不照搬海洋主题。

不应该照搬什么

不要把所有页面做成深色天气仪表盘；财务数字仍需比装饰图形更醒目。

B · Moonlitt

沉浸焦点 · 场景化控制

Apple Design Awards 2026 · 交互获奖

美区 App Store：4.7 / 869 条（总分满分 5；评分不是 UI 专项评分）

看哪里

一个全屏主场景，少量悬浮控件，时间标记直接附着在对象上。主内容不被一层层面板打断。

我建议借鉴什么

专注进行中的单一焦点；健康详情页的主趋势。把主要操作放在任务附近。

不应该照搬什么

不复制摄影背景和重透明玻璃到记账列表；可读性和 PWA 性能优先。

我的判断：先选一种主语言，不混成五种风格。

对 LifeIndex 而言，我建议先在 A 的「数据秩序」与 C 的「生活感」之间选择主方向。B、D 更适合专注或完成反馈中的局部体验；E 用来检验操作是否一眼可懂。以下是设计推断，不是已经批准的方案。
