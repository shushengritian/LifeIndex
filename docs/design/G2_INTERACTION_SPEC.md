## 1. 页面职责与结构决策

保留五项主导航，不再增加底部项目。健康首页不展开四套完整统计，采用摘要 + 行式详情入口；体重/运动历史用独立页面，不在首页“加载更多”。这样为长期记录保留空间，代价是查历史多一次进入动作。习惯详情承载连续天数、热力图和编辑入口，健康首页只保留当天打卡。今天不增加时间线数据模型。

| 设计面 | 自上而下的信息顺序 | 主操作 / 次操作 | 返回与上下文 |
| --- | --- | --- | --- |
| S01 今天 | 日期与标题；记账/专注快捷；今日习惯；简短金额/专注摘要 | 记一笔、开始/继续专注；进入业务页 | 从快捷表单保存/取消回今天；记录成功可进入对应日期详情 |
| S02 记账 | 月份切换和新增；日历；月收入/支出/结余；所选日明细；回顾入口 | 新增账目；点记录编辑；更多回顾 | 月/日/滚动仅保存同会话 UI 上下文；表单失败不改变选择 |
| S03 专注 | 当前状态；事项与计时；主动作；历史入口 | 空闲开始、运行时提前结束；取消；次要字段折叠 | 已开始会话允许离开并继续计时，返回读取时间事实；未提交草稿需保护 |
| S04 健康 | 四个轻量分组：体重、运动、戒烟、习惯 | 每组明确记录/打卡；摘要行进入详情 | 子页返回健康，恢复原滚动；不回顶部重置 |
| H01 体重记录 | 最新值/已有趋势；目标入口；按日期分组的完整历史 | 新增；点记录编辑；编辑内删除 | 分页/分批只是呈现，不能隐藏最早记录；删末项回邻近日分组 |
| H02 运动记录 | 本周摘要；完整日期列表 | 新增；编辑/删除 | 与 H01 一致，无自动习惯联动 |
| H03 习惯详情 | 习惯名/状态；当天动作；连续天数/完成统计；14 周热力图 | 打卡/撤销；编辑、暂停/恢复按现有业务 | 从健康/今天进入，返回来源；点热力图日查看状态，不隐式补写 |
| S05 戒烟 | 计划状态/计划时区；经过时间；今天状态与记录；7 日/月回顾；管理 | 记录吸烟/烟瘾；符合条件的快照/全天确认 | 健康摘要进入；选日与月保留；结束/隐藏不删历史 |
| S06 设置 | 分类管理（折叠）；外观；数据与安全；其他 | 行式管理入口；备份/恢复 | 主题保留系统/浅/深；退出恢复预览不写库 |
| S07/08 URL Action | 预览字段与来源说明；执行/结果 | 明确确认或回应用 | 保留既有 fragment/校验/去重；不展示原始敏感 URL |

拟议子路由可使用 `/health/weight`、`/health/activity`、`/health/habits/:id`，仅为设计意图，G4 后 LLD 决定实现。今天/健康主导航不变化；原 `/habits` 兼容重定向保留。详情页可保留底部导航，但表单打开时其背景不可操作。

## 2. 任务流程

箭头是操作顺序；每个流程应用下节统一表单状态，不重复发明确认方式。

### J01–J03：首次使用、记账与健康记录

- 首次进入 → 今天空摘要（不伪造零余额与“无记录”的等价）→ 明确“记一笔”/“开始专注”/进入健康。空健康卡提供记录入口，习惯无数据直接“创建习惯”，不强制引导所有模块。
- 记账 → 选择月/日 → 新增（继承选日；从今天则用当前本地日）→ 金额/分类/日期，备注可选 → 校验 → 保存 → 原来源成功反馈。编辑修改日期后：留在原来源，反馈“已保存”，提供“查看记录”进入新日期；不静默把用户带到另一个月。删除说明记录日期/类别与永久删除后果，确认后刷新相关日/月汇总。
- 体重/运动 → 组内新增 → 对应短表单 → 保存 → 摘要和历史同步。详情列表能浏览全部旧记录 → 点条目编辑 → 保存留在该日期上下文。目标入口设置/修改/清除，清除只去除目标，不删称重历史。

### J04–J06：习惯、戒烟与专注

- 创建习惯 → 表单（名称、既有计划与字段）→ 健康今日列表。打卡是直接可撤销的动作，进行中禁重复，失败维持原状态；“已完成”可见并可撤销，不另弹成功确认。点名称 → H03 → 连续天数/统计/热力图；编辑/暂停保留历史。非计划日按既有规则展示，不能将未记录误算失败。
- 戒烟无计划 → 开始计划 → 开始时间必填、原因/估算可选 → 保存 → 未来准备中或进行中。计划时区不可变，起点/估算基线限制保留。
- 进行中 → 今天“截至此刻未吸烟” → 快照，不写成“今天全天无烟”。历史完整日在可确认条件满足时才显示“确认全天未吸烟”。有吸烟记录的日期不提供冲突确认。记录吸烟成功会撤销该日已有无烟确认；删除吸烟记录后的日期仍需依据事实重新确认，不自动变绿。
- 戒烟管理 → 结束计划（只停止后续记录并保留历史）/取消未来计划/隐藏入口；每种动作按真实后果命名。烟瘾结局、诱因、快照、全天确认、未记录分别显示，不添加医学结论或新连续天数指标。
- 专注空闲 → 输入事项、选择时长（25/50/自定义，仍按现有限制），可选分类/备注折叠 → 开始 → 进行中。返回其他页不停止会话；后台恢复用绝对结束时间核算。提前结束 → 明确确认 → 历史；取消 → 说明不计入完成记录 → 确认。到期按既有模型完成，不依赖后台动画；没有暂停按钮。历史编辑修改已允许字段，不能重写计时模型。

### J07–J10：设置、备份、更新、外部动作

- 分类默认折叠 → 对应收/支/专注/运动分类 → 创建或改名表单；归档说明仍保留历史。外观独立长条 → 系统/浅/深选择，保存失败回到原选择并反馈。
- 导出 → 生成 → 系统分享/文件保存 → 提醒用户确认文件存在。取消分享不宣称已有可恢复备份。
- 恢复 → 文件选择 → 校验中 → 不合法则拒绝并保留当前库 / 合法则预览格式、导出时间、分类/记录数量、替换范围 → 明确“替换本机数据” → 替换中禁止二次提交 → 成功刷新全部视图 / 失败说明当前数据未被替换。旧备份会清空其不含的戒烟数据，预览必须突出说明。文件名不是安全证明。
- 更新可用 → 稍后 / 立即更新。脏输入或保存中时立即更新不可执行，并说明先保存或放弃。离线提示不阻断本地记录；更新失败可重试，不能建议清库。
- URL Action → 参数合法预览 → 明确确认 → 执行一次 → 成功/已处理/失败结果。拒绝参数时不写库，不把敏感内容保留在 URL 或日志；返回不重复执行。

## 3. 统一状态和退出协议

| 状态 ID | 界面/动作 | 转移与数据规则 |
| --- | --- | --- |
| E0 干净 | 初始化字段；取消/关闭可用 | 无修改退出直接回来源；初始默认值不算脏 |
| E1 已修改 | 保留输入；保存可用 | 返回/取消/Escape/路由离开进入 E6；恢复全部初始值后回 E0 |
| E2 校验失败 | 字段旁具体提示；焦点到首个错误 | 不写入；修正后可提交；其他输入不丢 |
| E3 保存中 | 原按钮显示“保存中…”；只读/禁重复；不要跳动布局 | 禁再次提交与可控退出，说明正在保存；操作实际结束才解除，不以超时当作已失败 |
| E4 写入失败 | 表单内“未能保存，输入已保留”与重试 | 回可编辑状态；复用同一次操作身份（已有支持时）；不重复追加 |
| E5 成功 | 关闭编辑、更新相关视图、短非阻断反馈 | 返回来源和焦点；保存实际成功后才反馈，不能提前清草稿 |
| E6 放弃确认 | “放弃尚未保存的更改？”；继续编辑 / 放弃更改 | 默认焦点继续编辑；继续保留全部输入；放弃仅清本次草稿并完成原退出意图 |
| Q0 读取中 | 标题/返回可用，内容加载状态 | 不将暂未读到数据当作空库 |
| Q1 读取失败 | 局部错误 + 重试 | 已显示的数据可保留并标记；不让失败模块清空其他摘要 |
| D0 风险确认 | 对象、后果、取消与明确危险动作 | 默认取消；确认后 D1；取消零写入 |
| D1 风险动作中 | 防重复执行、显示进行中 | 失败回 D0/错误说明并可重试，不能假装成功 |

退出来源矩阵：

| 来源 | 干净 | 脏 / 失败 | 保存中 | 边界 |
| --- | --- | --- | --- | --- |
| 可见取消/关闭、Escape | 退出 | E6 | 不退出 | 全模块同规则 |
| 背景点击/向下拖动 | 表单默认不关闭；动作面板可关闭 | 不关闭 | 不关闭 | 本版不依赖拖拽手势，也不实现假拖动把手 |
| 底部导航 | 无模态时正常导航 | 拦截并 E6 | 暂不执行 | 模态打开时背景 inert，不允许点击穿透 |
| 详情返回/浏览器返回 | 回正确来源 | 设计目标为拦截并 E6 | 等待当前操作结束 | HashRouter 实施方式在 LLD 验证，不假装浏览器所有返回可拦 |
| 刷新/关标签/系统终止 | 正常 | 尽力使用浏览器允许的提示 | 尽力保护 | 系统可能不触发事件；本版不承诺跨重启草稿，说明未保存输入可能丢失 |
| 更新激活 | 可执行 | 禁用并提示先处理输入 | 禁用 | 保留既有 SW 安全规则 |

本阶段选择“明确放弃”而非自动持久草稿，避免新增数据库字段。实现若无法可靠拦截内部导航，需重新提交可用替代，不默默降级为直接丢弃。

## 4. 移动端、焦点与滚动规则

- 短表单以屏内底部面板呈现，标题和取消清晰；操作区位于面板内底部。内容溢出时仅表单内容滚动，背景锁定；面板高度随可用视口调整，不假设固定键盘高度。
- 输入金额/数值使用适合的键盘；日期时间控件占满同一内容宽度。初始焦点到首个适合输入的字段；日期为主的表单不无故打开无关键盘。
- 模态背景 inert、焦点留在模态、Escape 遵循取消；关闭回触发器，触发器被删除则回列表标题/相邻入口。焦点不可落在隐藏的底部导航。
- 软键盘展开必须能滚到当前字段、错误与保存区；不把面板按钮绝对定位在被键盘覆盖的位置。真实 Safari/Home Screen 的 visual viewport、焦点与安全区由 G5 验证。
- 列表保持页级滚动，避免卡片内多层滚动。完整历史按日期分组分批呈现，提供明确“继续加载”或稳定滚动，不声称只有最近几条数据。
- 320/390/430 宽度不横向溢出；中文长名称换行，金额完整读取，关键触点目标 44px。日历小格例外在 G3 实测并提供日明细替代。
- 深浅主题共享同一信息与动作优先级；G2 灰阶不锁定色值。大字体/减少动态效果不能隐藏信息。

## 5. 文案与危险动作

| 场景 | 标题/说明 | 按钮 |
| --- | --- | --- |
| 放弃输入 | 放弃尚未保存的更改？关闭后本次输入不会保留。 | 继续编辑 / 放弃更改 |
| 删除账目/健康记录 | 删除这条记录？显示适当对象摘要；删除后无法在应用内撤销。 | 保留记录 / 删除记录 |
| 清除目标 | 清除体重目标？已有体重记录不会删除。 | 保留目标 / 清除目标 |
| 归档分类 | 归档此分类？历史记录保留，新记录不能继续选择它。 | 取消 / 归档分类 |
| 取消专注 | 取消本次专注？不计入完成记录。 | 继续专注 / 取消本次专注 |
| 提前结束 | 提前结束本次专注？按实际经过时间记录。 | 继续专注 / 结束并记录 |
| 结束戒烟计划 | 结束当前计划？保留历史，停止向该计划新增记录。 | 继续计划 / 结束计划 |
| 恢复 | 替换本机数据？这不是合并；当前数据将被选中的备份替换。 | 返回预览 / 替换本机数据 |
| 保存失败 | 未能保存，输入已保留。请检查后重试。具体校验错误放字段旁。 | 重试保存 |
| 离线 | 当前离线，仍可在本机记录。 | 不强制确认 |

对象摘要只显示在用户界面，不写日志。禁止用羞辱性健康文案、“戒烟成功”等未经事实支持的结论，也不把任何未记录状态标成失败。

| 用例 ID / 页面 | 设计状态与验收 | 低保真演示范围 |
| --- | --- | --- |
| G2-T01 今天→记账 | 直接表单、取消回今天、成功更新来源 | 可点击合成闭环 |
| G2-T02 记账 | 选日继承；E2/E3/E4/E5/E6；删除确认 | 可点击；提供模拟失败开关 |
| G2-T03 健康历史 | 摘要→40 条历史→最早条目→编辑→返回 | 体重可点击；运动同类结构 |
| G2-T04 习惯 | 创建/编辑状态复用 E0–E6；打卡撤销；H03 热力图 | 打卡/撤销/详情可点击；创建字段按现有规格，稿中标注未展开 |
| G2-T05 戒烟 | 未开始/准备中/进行中/已结束/隐藏；快照/fullDay/吸烟/未记录 | 静态状态说明与导航；不模拟完整事实计算 |
| G2-T06 专注 | 空闲/输入/进行中/结束/取消/失败；无暂停 | 开始、取消、提前结束模拟；后台真实恢复留产品测试 |
| G2-T07 设置 | 四独立组、分类折叠、外观、恢复预览/确认/结果 | 分组与合成恢复预览可点击；不访问文件/真实存储 |
| G2-T08 全局退出 | 干净/脏/保存中、Escape、继续/放弃、返回来源 | 表单取消/Escape可点击；浏览器返回、刷新拦截仅规格，G4/G5 验证 |
| G2-T09 更新/离线 | 有草稿不可激活、离线可写、失败重试 | 规格，不注册 SW |

G2 的目标是任务流程可审核，不是 G4 全状态交互覆盖。低保真未实现的系统能力明确标识，不做“点击成功”等虚假反馈。

## 7. 操作步数比较

沿用 G1 计数：点击/选择算动作，文字输入独立，不计逐键；起点一致，不包含应用启动。

| 任务 | 现有结构基线 | G2 目标 | 取舍 |
| --- | --- | --- | --- |
| 今天记账（填金额/选分类/保存） | 4 次 + 输入 | 3 次 + 输入 | 去除到记账页后再次找新增；本稿分类合成默认不代表产品可无分类保存 |
| 记账页选历史日新增 | 4 次 + 输入 | 4 次 + 输入 | 保留明确选日/分类，不为数字压缩步骤 |
| 健康新增体重 | 2 次 + 输入 | 2 次 + 输入 | 提升入口与失败体验，不声称步数减少 |
| 查看最近范围之外的体重 | 无直接完整入口 | 摘要历史入口 1 次 + 必要滚动/加载 | 补全可达性，不能计算“节省百分比” |
| 习惯打卡/撤销 | 各 1 次 | 各 1 次 | 可见反馈与可靠撤销优先 |
| 取消专注 | 2 次 | 2 次 | 保留风险确认，不做误触即取消 |

本稿新增/保存演示采用有限字段，不能以它的点击数替代完整产品计数。G4 用同一完整 fixture 和全字段原型复测，G5 再对产品复测。

## 8. G2 审核要点

请审核：①健康摘要与独立历史/习惯详情是否清晰；②今天快捷操作是否直接；③默认底部表单、统一放弃确认、危险操作明确后果是否符合预期；④专注只突出计时，戒烟保留严格事实状态。通过后进入 G3 三个双主题高保真样板，不自动进入实现。
