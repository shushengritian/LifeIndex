日期：2026-09-15；现状依据 2.1.1 / `74ef3ff`。G1 范围已确认；后续设计见 [G2 交互规格](G2_INTERACTION_SPEC.md)。下列“现有”与“拟议”严格分开；页面清单不是已经完成的设计稿。

## 1. 当前路由与职责

路由证据：`src/app/App.tsx:51`；公共结构：AppShell 顶部上下文/仅本机、底部五项导航。路由中没有独立体重、运动或习惯详情页。

| 页面 ID / 路由 | 当前内容与入口 | 返回/上下文 | 拟议方向（待批准） |
| --- | --- | --- | --- |
| S01 `/today` | 默认首页、摘要、习惯状态、记账/专注快捷链接 | 底部导航；快捷记账目前只跳 finance | 简短摘要 + 直接启动任务，返回来源明确 |
| S02 `/finance` | 月日历、选日账目、月汇总、分类/月趋势；新增与行内编辑删除 | 选日状态在页内，新增继承选日 | 日历优先、紧凑汇总、日明细；保留年月/选日/滚动上下文 |
| S03 `/focus` | 空闲表单或进行中计时，今日/周/月汇总与历史 | 切页可丢未保存草稿；活动会话另有恢复逻辑 | 计时中心、次要输入折叠、历史有清晰层级 |
| S04 `/health` | 体重、运动、戒烟卡、习惯与统计 | 戒烟链接进入子路由；其余多数页内操作 | 摘要首页 + 各子模块回顾入口 |
| S05 `/health/cessation` | 计划、快照、7 日/月视图、选日、事件与管理 | 返回健康；页内选择历史日 | 保持独立功能页面与严格状态含义 |
| S06 `/settings` | 分类、外观、数据与安全、其他 | 页内操作与系统文件/分享 | 四个独立长条分组；分类默认折叠 |
| S07 `/action/:actionType` | 外部 URL Action 参数处理/确认 | 跳转结果页 | 保留入口契约、错误与重复操作防护，不混入普通导航 |
| S08 `/action-result` | Action 结果反馈 | 回到应用的有效路径 | 与统一成功/失败反馈保持一致 |
| 重定向 | `/` → today；`/habits` → health；未知路径 → today | 兼容入口 | 保留兼容，不让书签因重设计失效 |

## 3. 核心流程与保护点

这些是现有链路的盘点及待明确的契约，不是 G2 已定稿流程。

| 流程 ID | 主要链路 | 必须设计的分支 |
| --- | --- | --- |
| J01 首次使用 | 今天空状态 → 选任务 → 首条记录 → 摘要 | 不强制完成全套引导；取消无数据；失败继续输入 |
| J02 记账 | 选年月/日 → 新增/编辑 → 校验 → 保存 → 日明细/月汇总 | 分类失效、金额格式、日期改变、失败、重复点击、取消与返回 |
| J03 健康记录 | 摘要 → 新增体重/运动 → 保存 → 摘要/历史 | 数值/日期错误；最旧记录访问；删改后上下文；目标清除 |
| J04 习惯 | 创建 → 今日打卡 → 撤销 → 连续天数/热力图/统计 | 非计划日、空历史、编辑/归档、失败；不由运动自动打卡 |
| J05 戒烟 | 创建计划 → 活动/未来开始 → 快照/事件 → 历史日 → 管理 | 未记录、当日快照、全天确认、吸烟失效、删除不恢复确认、结束/隐藏 |
| J06 专注 | 输入 → 开始 → 前后台恢复 → 到期/提前结束/取消 → 历史 | 草稿离开、计时一致、重复结束、失败、历史编辑；无暂停 |
| J07 设置 | 折叠分类/改名归档；外观选择 → 持久化 | 失败回滚、被历史引用分类保留、两主题全部状态 |
| J08 备份 | 导出 → 系统存储 → 用户确认文件；导入 → 校验 → 预览 → 明确替换 → 结果 | 取消、坏文件、旧版本、部分非法内容、配额/事务失败，不先覆盖后校验 |
| J09 更新 | 更新提示 → 稍后/立即 → 激活 → 启动读取旧数据 | 脏输入、保存中、离线、失败重试；服务器版本与客户端运行版本分开 |
| J10 URL Action | 参数解析 → 校验/确认 → 执行 → 结果 | 缺参数、非法类型、重复请求、失败；返回不能误重复写入 |

## 5. 下一阶段拟议页面集合

保持 S01–S08；拟新增设计面 H01 体重历史、H02 运动历史、H03 习惯详情/统计（可独立页面或明确子视图，G2 比较）。不因此新增 store 或计算模型。戒烟继续独立页面，避免在健康首页塞完整月历和事件列表。

G2 每个页面规格必须包含：职责、来源、返回目的地、选中日期/滚动/筛选上下文、主次动作、表单状态、读取错误/重试、键盘与辅助技术规则。G3 首批仅记账首页、健康首页、新增记录表单双主题样板；G4 扩展全部设计面。

原型一律用显式标记的合成数据、隔离存储，不写真实 IndexedDB。现存独立视觉探索不计为已批准设计，不用它替代本轮审计或后续阶段门。
