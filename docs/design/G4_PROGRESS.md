FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance。规范由现有 docs/design 文档承载，未批准的新页面不设为生产真相。

## B2 目标与习惯交互契约（2026-09-19）

- 体重目标入口为健康体重面板底部整行中的目标按钮。20–500 kg、一位小数；修改和清除不影响体重记录，清除需确认。失败保留原值和草稿，可重试。
- 今天/健康共用习惯列表，名称进入详情，右侧独立按钮打卡或撤销。仅显示启用且当日计划内的习惯；管理页能找到已暂停项。
- 详情展示当前/最长连续、本月完成率、累计次数、14 周热力图。统计从同一组内存记录计算，与现有 habitDomain 的计划日口径对齐：今日未完成不打断昨日连续；本月分母截至演示今天；暂停不改写计划历史。
- 热力图列为周、行从周一到周日；勾号与边框同时区分状态。选日只查看，不自动补打卡。390px 可展示完整 14 列；320px 保持 24px 日期触点，图内横向滚动，不使整页溢出。完整触达优化和读屏检查在 D。
- 管理支持新增/编辑名称、图标、颜色、星期计划、开始日期、备注，暂停/恢复保留打卡；修改计划说明重算影响。原型图标/颜色是代表性子集，开始日期限 2000–2100 用于防止无界演示计算，不视为生产字段范围决策。
- 保存中锁定控件；关键分支与结果使用固定事件日志，不记录名称、体重或备注。新增、目标修改使用原有草稿退出保护。

证据：[B2 检查记录](reviews/g4-b2/README.md)。下一批 C 为戒烟与专注完整流程；分类管理编辑及 D 全状态检查仍未完成。未修改生产代码、数据库或线上部署。

## C1 专注交互契约（2026-09-19）

- 计时由开始/预期结束时间计算，无暂停。不足一秒不计入；提前结束保留实际秒数；到期按预期终点封顶。结果保存失败时保留待保存状态，重试不延长时长，不重复计数。原型仍仅内存，不宣称刷新或后台持久化可靠性。

- 验证工具折叠放在页面末尾：模拟写入失败、推进原型时钟到结束。不修改设备时钟，不触碰线上记录。演示日期为 2026-09-18；分类仅代表性样本，正式分类管理仍待补齐。

## C2 戒烟交互契约（2026-09-19）

- 健康摘要进入独立戒烟页：状态与记录依据、截至现在快照、吸烟/烟瘾入口、7 日选日/月历、选日事件、完整日/覆盖/估算。未知日期不当作无烟；过去快照不当作完整日；计划外日期不得确认。
- 开始计划只需起点；原因可选，估算三项必须全填或全空。起点、时区、基线固定；原因可编辑。未来取消为空区间，不阻止重新开始；结束后停止新增但保留历史与合法历史编辑。管理可切换计划。
- 吸烟新增/编辑支持时间、支数和诱因，写入前明确冲突确认；成功才撤销目的日期确认。移动/删除不自动恢复旧日期确认。烟瘾包含 3 分钟可选小休息、感受、诱因；感受可随时保存，不与专注记录混用，不作治疗承诺。
- 今日快照与过去完整日分别确认/撤销；当天尚未结束不开放全天确认。所有关键写入失败保留原记录与表单，复用草稿退出确认，固定事件日志不包含原因、数量、价格或日期。
- 隐藏只隐藏健康摘要。设置“其他”增加戒烟管理入口，仍保留四个独立分组；可恢复健康入口，计划不因隐藏而结束。
- 原型控制器为 `g4-cessation.js`，仅合成内存数据。时区固定 Asia/Shanghai、当前时间固定 2026-09-18 12:00，用于复现状态，不是生产多时区引擎。所有日期/时间输入明确标记该时区；未改生产存储、迁移和医疗内容。

证据：[C2 记录](reviews/g4-c2/README.md)。C3 进展见下；G4 未整体通过，未进入生产实现或发布。

## C3 分类交互契约（2026-09-19）

- 设置分类管理仍默认折叠，支出/收入/专注/运动分别进入独立页。使用中与已归档分开，显示引用数量。编辑表单包含 1–40 字名称、图标/颜色选择、实时预览，分类所属模块/收支类型不可变。
- 新增后对应记录入口立即可用；名称和视觉标记通过稳定 ID 在历史列表同步显示，不修改金额、时长、日期或备注。新增/修改失败保留表单和原分类；归档/恢复均确认，并说明放弃未保存草稿。
- 归档不删除记录、不迁移到其他分类：新增选项排除归档项；编辑既有记录允许保留其原归档分类。专注仍可选“未分类”。所有分类归档后提供创建/恢复指引，禁止保存缺少必填分类的账目/运动。
- 原型的运动样本从中文标签改为内存分类 ID，引入共享 `g4-categories.js`；不涉及真实 IndexedDB 迁移。图标/颜色使用既有海蓝样板代表性集合，不声称覆盖生产所有枚举。
- 分类名称所有 HTML 展示经过转义；日志只记录固定动作与模块，不写用户名称。
