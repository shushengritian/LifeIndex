## Direction contract

THESIS：常用操作落在内容旁，完整圆环明确表达专注；拒绝把链接、按钮、说明文字混为一层。

OWN-WORLD：延续 Ocean 深浅主题与系统字体；24px 线性 SVG、44px 操作触点、单列清晰内容；分类色仅用于识别。参考用户截图的操作语法，不复制其品牌和私人记录。

STORY：今天直接进入记录；健康与记账就地新增、点内容查看；专注准备后进入独立计时场景，退出场景不结束计时。

FIRST VIEWPORT：今日摘要为整宽可点击内容；记账保留完整月历，顶端仅新增，报表使用独立内容行；健康节标题仅一个写入动作，下方内容进入历史；专注完整圆环居中，事项/剩余在圆内，运行状态在页头，停止在圆外下方。

FORM：用户已指定番茄 TODO/记账本参考方向，沿用既有 code-led 隔离原型。手动模式，无随机 seed 或启动器执行；非品牌重做。

FINISH：交付浏览器可看的设计原型、已知模拟边界、独立审查与文档；审核结论不代替用户批准，不自动进入生产实施。

### 专注

准备页保留事项和时长选择，用圆形播放开始；运行页完整 360° 轨道，12 点起顺时针填充已用时间，中央为剩余 mm:ss，下方实际已用/目标。轨道不随进度消失，0% 和 100% 也保持完整外形。左上收起回准备摘要；计时不停止；停止图标打开“保存并结束 / 继续专注 / 放弃本次”的明确确认。当前无暂停能力，因此不画暂停按钮。

自然结束 → 正在保存 → 已保存结果；失败 → 待保存且保留结果、可重试。统计只计已保存。生产仍以持久化时间戳为准，不能移植原型内存计时。

上段为后续正式实现必须保留的状态契约，**本轮原型未展开保存中/失败/重试/独立结果页**；当前演示自然或提前结束后提示成功并回准备页。此处不能签为“完整专注状态设计验收通过”，下一轮需补状态稿再交开发。已完成的准备/运行/收起/结束确认可单独审核。

### 记账 / 健康

新增用 +，查看用内容本身，不再把独立箭头按钮与 + 并排。报表是带柱状图标的独立内容行。录入上栏 X / 标题 / ✓，正文仍有可见字段标签。记账金额是主视觉，一级分类彩色图标、二级仅名称。戒烟事件选择在 sheet 内保留“未吸烟/吸烟/烟瘾”选项名称，不能仅靠表情表达。

### R1.1 防误触规则（用户要求优化后）

| 区域 | 查看 | 写入 |
| --- | --- | --- |
| 今日账目 | 点击收支摘要，进入记账 | 标题右侧 + |
| 今日专注 | 点击统计摘要，打开记录入口 | 标题右侧播放，准备/返回计时 |
| 体重 / 运动 | 点击数值、趋势或记录区域 | 标题右侧 + |
| 戒烟未建计划 | 无独立详情，整卡进入创建 | 与创建入口合一，不重复显示 + |
| 戒烟已有计划 | 点击计划摘要 | 标题右侧 + 记录事件 |
| 习惯 | 点击名称区域进入详情，健康另有“全部习惯”内容行 | 行尾单独打卡按钮 |
| 记账报表 | 点击日历下的“收支报表”内容行 | 页头仅保留 + |

- 标题写入与下方查看区域相距16px；同一行的习惯名称与打卡也留16px，不依赖不可见的扩大点击层。
- 内容区域使用原生button、最小高64px及明确无障碍名称；箭头只是装饰，不独立聚焦，不拥有点击处理。
- 卡片容器没有click监听，查看和写入按钮互为兄弟，不嵌套、不覆盖；点击一次只执行一个动作。不使用 stopPropagation 掩盖错误结构。
- 可点击区域有按下/键盘焦点反馈；hover仅用于支持鼠标的环境。保留触屏阅读提示和独立名称，不依赖长按tooltip。
- 详情仍是本稿的说明占位，此轮优化入口而非扩展完整业务实现。未声称真机误触率已降低。

### 尺寸与状态契约

- 外边距20px、卡内16px、节间24px、工具间8px；320px外边距16px。
- 图标24px，触点44×44px，主播放/停止64px；标题/操作组垂直居中。
- 44px 约束指独立操作图标；七列日历窄屏日期格宽度例外（390约42px、320约34px），需结合真机误触测试，不能宣称所有触点都达到44px。
- 操作区到分隔线至少16px，不将按钮边界当作分隔线；分隔线仅用于同组记录，不每个区域都加线。
- 保留隐藏滚动指示器；内容仍可滚动，导航占独立布局行，不能通过禁用页面滚动掩盖内容溢出。
- 无障碍名称明确区分新增与查看；focus-visible 清晰。tooltip 只作补充，不作为触屏识别的唯一提示。
- 图标保存需覆盖禁用、提交中、成功、失败；有改动的草稿关闭需确认。破坏性确认保留文字，这是风险信息，不是普通文字 CTA。
