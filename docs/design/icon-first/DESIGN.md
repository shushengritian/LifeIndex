# LifeIndex icon-first 原型源码核对稿

后续授权：R1.1已由用户要求进入开发与部署（ADR-0022）。下文为设计阶段源码核对及当时边界，不表示当前仍缺实施授权。正式代码与验证见ICON_FIRST_IMPL及3.2.0发布记录。

## Overview

2026-09-21。状态：**设计提案，尚未用户批准**。这是既有 Ocean 系统内的局部操作重设计，不是新品牌、全局系统替换或正式功能交付。正文及 frontmatter 仅描述此原型；源码取值不自动成为产品规范。

本轮针对三个问题：专注圆弧不完整；今日新增与查看不齐；健康和记账文字操作过多、距离过近。提案采用准备页与完整圆环运行页、今日整宽单列卡片、标题右侧固定操作组，以及录入页 X／标题／✓。模式为 Operate，沿用 Ocean 深浅主题与系统字体，不另造品牌隐喻。

证据范围：逐项静态核对 [BRIEF.md](BRIEF.md)、[app.css](../prototypes/icon-first/app.css)、[app.js](../prototypes/icon-first/app.js)，对照 [既有 DESIGN.md](../operation-refresh/DESIGN.md)，并参考 [Impeccable document 规范](/Users/fh/.codex/skills/impeccable/reference/document.md) 的章节顺序及实际值提取方法。未启动浏览器、未读取 computed style、未执行交互测试；以下“实际”指源码声明或处理分支，不是渲染实测通过。

用户指定的局部文档边界优先于 document 规范的全局生成流程：保留旧 DESIGN 和 `.impeccable` 配置，不生成全局 sidecar，不合成色阶，不开展新品牌访谈。旧稿的开发授权、审核记录和测试结论不转移到本稿。

### R1.1 操作区分离（2026-09-21）

用户要求优化相邻 + / 箭头的误触风险。本稿改为单一标题动作，内容区域整体查看；下文 R1 的“固定操作组”在今天/健康中不再容纳两个相邻按钮。旧版全局设计文件保持不动。

- `.content-link`：全宽原生button、最小64px高、左右内容/装饰箭头gap16px、圆角12px；有无障碍名称，正文数据仍可读。箭头 `aria-hidden`、`pointer-events:none`，不新增焦点。
- section header 与内容之间保留16px；父卡片不绑定动作。读写为兄弟按钮，无嵌套/透明覆盖层。
- 习惯名称按钮最小64px高，与44px打卡按钮间距16px；健康和今日共用同一helper，完成/撤销名称随状态变化。
- 未建戒烟计划为单个完整卡片按钮，内边距20px 16px、圆角16px；建计划后变为标题 + 和下方计划摘要。
- 记账页头仅新增，报表进入日历下独立内容行；其名称不是裸文字CTA，而是整行导航信息。
- 可点击内容支持active/focus-visible，hover仅在鼠标环境启用。保留隐藏滚动指示器及内容滚动，不改计时、数据层和已披露的详情占位。

本次仅定点更新交互契约与对应源码描述，不将R1独立审核扩展成R1.1全稿审核；本次实际检查见REVIEW。

## Colors

Ocean 的浅雾蓝背景与深海蓝表面延续既有方向；青蓝承担操作与选中状态。frontmatter 记录两个主题的全部 11 个根变量，`light-*`／`dark-*` 是本文件的主题区分命名，源码仍使用 `--bg` 等短名，不表示新增全局变量。

| 源码变量 | 角色与实际用途 |
| --- | --- |
| `--accent` | 主操作、图标按钮、选中态、圆环进度、曲线和报表条形 |
| `--tint` | 弱化操作、选中分段、分类选中背景 |
| `--bg` / `--surface` | 页面背景／卡片、导航、输入、dialog 表面 |
| `--ink` / `--muted` | 正文及主读数／辅助信息 |
| `--line` | 分隔线、输入边框、曲线参考线、条形底色 |
| `--track` | **本稿新增的独立完整圆环轨道色**；与进度色、普通分隔线分工，不应回退为局部弧线 |
| `--orange` / `--purple` | 餐饮、运动／阅读、旅行等语义图标；不作为全局状态色 |
| `--green` | 已定义绿色语义变体，但当前页面模板没有实际调用绿色 glyph；不能据此宣称存在额外健康状态 |

分类底色实际为 `color-mix(in srgb, var(--orange/green/purple) 12%, var(--surface))`。主图标按钮浅色文字取 surface，深色取 bg。源码还存在局部字面色：遮罩 `#08152580`、危险文字 `#ba3737`、错误浅色 `#be3434`／深色 `#ffa4a4`；它们不是已统一的语义 token。未测对比度，尤其不能把危险文字和深色日历选中态判为无障碍通过。

## Typography

全稿使用 `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`；`font-synthesis: none`。没有独立展示字体或等宽字体文件；数字通过 `tabular-nums` 对齐。按钮、input、select 使用 `font: inherit`；正文基准字号未显式声明，不能把浏览器常见默认值写成已配置 token。

| 层级／场景 | 源码声明 |
| --- | --- |
| 页标题 h1 | 28px，字距 −0.02em；字重、行高未单独声明 |
| 节标题 h2／小标题 h3 | 18px／16px |
| strong | 字重 650，等宽数字；计时器覆盖为 400 |
| p | 行高 1.55，上下 margin 8px |
| small／字段 label | 13px／14px；label 内 gap 8px |
| 摘要／健康主读数 | 26px／32px；健康单位 16px，字距 −0.02em |
| 圆环事项／倒计时 | 17px／`clamp(44px, 16vw, 64px)`；倒计时行高 1、字距 −0.03em；≤340px 时覆盖为 48px |
| 记账金额 | 46px，输入框高度 64px，居中 |

不同于旧稿的正文15px、表单16px、节标题17px约定，本稿应以这些源码声明为准；尚未批准迁移到全局字号系统。长事项有 `overflow-wrap: anywhere`，不等于所有长名称、大字模式已验证。

## Layout

页面为 `100dvh` 两行 grid：内容 `minmax(0, 1fr)`，底栏 `auto`。body 隐藏溢出，但 `#screen` 独立 `overflow: auto`，隐藏滚动条仍允许内容滚动。运行和记账录入场景隐藏底导航并改为单行 grid。

| 结构 | 实际值与边界 |
| --- | --- |
| 内容外边距 | 顶部 `max(24px, env(safe-area-inset-top))`，左右20px，底部28px |
| 卡片／节间 | 卡内16px；相邻 section 间24px |
| 页头／节头 | flex 垂直居中、space-between、gap16px、最小高44px；下间距24px／16px |
| 固定操作组 | flex、不收缩、gap8px；两个44px按钮通常占96px。是布局组，不是 fixed 定位 |
| 记录行 | 最小高64px、gap12px；后续行顶部1px线、padding-top16px、margin-top16px |
| 今日 | 三张整宽卡片纵向排列；卡内收支、专注统计仍有并排数据，不是所有数字都单列 |
| 导航 | 五等列；最小按钮高56px；padding 为8px 10px及底部 `max(10px, env(safe-area-inset-bottom))` |
| 月历／分类 | 月历七等列、gap4px；一级分类四等列、行列 gap12px/8px；二级分类可换行 |
| dialog | 宽 `calc(100% - 24px)`、最大430px；最大高 `calc(100dvh - 32px)`；内边距24px；底部margin12px；整体可滚动 |
| ≤340px | 内容左右16px、卡内14px、操作组gap4px、日期最小高44px；并非统一保留卡内16px/工具gap8px |

今日及健康的标题和操作组采用同一居中布局，源码具备对齐基础；本轮未测中心线、实际分隔距离和横向溢出。编辑标题使用三个 flex 子项排列，并非保证标题绝对居中的三列 grid。记账页头 sticky，top 为 −24px、上下 padding8px；安全区和键盘下效果待测。dialog 头部没有固定，不能继承旧稿“头尾固定、中间独立滚动”的结论。

## Elevation & Depth

无 `box-shadow` 或模糊玻璃效果。层次由背景／表面色、弱化底色、局部边线与 dialog 遮罩表达。记账工具栏 z-index 为1；提示条固定在底部88px，未验证键盘遮挡。仅当 `prefers-reduced-motion: no-preference` 时 dialog 从下方12px进入，时长0.18s、ease-out；圆环未声明补间动画。

## Shapes

普通图标按钮44×44px、圆角14px；语义图标底块40×40px、圆角13px。卡片／导航项圆角16px；输入、分段、二级分类和确认按钮12px；日期格10px；dialog24px；报表条高8px、圆角4px。

线性 SVG 为24×24、stroke-width1.7、圆头圆角、无填充。准备页播放为56×56圆形，运行页停止为64×64圆形；**BRIEF 的“主播放/停止64px”尚未完全对齐**。

圆环容器宽 `min(100%, 322px)`、比例1:1，SVG viewBox 为320×320；轨道和进度均为圆心160/160、半径148的完整 circle。轨道描边3、进度4（SVG单位，随视口缩放）；旋转−90°使起点位于12点。轨道不使用 dash，进度 `pathLength=100`、dasharray 为 `100 100`，offset 按已用比例由100降至0。0%／100% 的完整几何来自持续存在的轨道；端点实际观感与100%停留时机未实测。

## Components

### 操作、名称与反馈

本稿使用“动作＋对象”的可访问名称，例如“记一笔”“查看今日账目”“记录体重”“保存账目”“关闭账目草稿”。图标本身 `aria-hidden`；`ib()` 同时给出 aria-label 和 title。加号用于新增，chevron／整行用于查看，chart 用于报表或专注记录，X关闭，check保存／确认，play开始／重入，stop结束，down收起。

名称依赖上下文，不能只叫“加号”或“对勾”。字段标签、分类名称、时长分段和破坏性确认文字保留。R1.1 今日与健康共用习惯行，完成/撤销按钮名称已统一按状态变化。

CSS 有3px accent焦点轮廓、3px偏移；按钮禁用 opacity0.4；通用 active 背景为 tint，变体效果受级联影响；无单独 hover 规则。不是每个图标按钮都通过 `ib()` 生成，不能声称所有按钮都有 tooltip。最新 BRIEF 已明确44px约束指独立操作图标，七列日历窄屏格宽为例外；这属于已声明边界，不是未披露的契约差异。其390宽约42px、320宽约34px的估值仍须渲染与真机误触检查，不能推广成“所有触点达标”。

### 准备与完整圆环运行

准备页事项必填并 trim，预置25／50分钟，自定义整数1–240；运行页事项、剩余 mm:ss 与“剩余时间”在圆内，“专注中”在页头，实际已用／目标在圆外下方，停止在圆外底部。因此 BRIEF“状态在圆内”未完全对应实际布局。

`Date.now() - started` 计算已用时间，1秒interval只触发更新。收起保留 started、可重入；没有暂停。停止打开“保存并结束／继续专注／放弃本次”确认。自然到时和主动保存均立即累加内存 savedSeconds、清空 started、回准备页并 toast；放弃不计入时长。**没有正在保存、待保存、失败重试或独立结果页**；最新 BRIEF 已明确这是模拟边界，完整保存状态链属于后续正式要求，不应再描述成 BRIEF 承诺本轮已实现。准备／运行／收起／结束确认可单独审核，但不能验收为完整专注状态稿；需补状态稿再交开发。没有持久化会话记录、后台恢复、多标签页锁或通知验证。

### 录入与草稿

记账为独立录入场景，健康体重／运动和创建戒烟计划使用 dialog；均表达 X／标题／✓。记账保存校验正数且最多两位小数，400ms模拟等待期间禁用保存按钮并阻断动作分发，之后仅写 `{ amount: Number(raw), category }`。没有保存失败分支；金额使用 Number 元而非生产整数分，不得移植为正式数据层。

记账有改动时关闭会确认；sheet 输入触发 sheetDirty，关闭和 Escape 经过 `requestSheetClose()`，二层放弃确认保留原 sheet DOM。这里只确认源码存在保护分支，不宣称原生dialog焦点循环、焦点恢复或键盘通过。保存中 input 未统一禁用；400ms期间输入可变化，不能称为完整提交锁。

**日期与备注仅展示录入布局，不进入保存记录。** 二级分类可选择但也未写入 ledger；切换一级／二级分类会重建录入DOM，日期、备注不保留。新建只重置金额及脏标志，分类沿用内存值。计划开始日期亦不读取，保存只将 plan 设为 true。这些均为模拟缺口，不是批准的产品行为。

## Do's and Don'ts

### Do

- 将完整circle轨道、单列卡片、固定操作组、X／标题／✓作为本轮待审提案，以源码和 BRIEF 差异共同交接。
- 保留可见字段语义、动作对象名称和破坏性确认文字；区分布局演示、内存操作与真实业务实现。
- 后续先取得用户对本稿的批准，再进入正式开发；生产实施后完成正式回归并获得发布授权，方可部署。回归须包括320／390／430宽度、568短屏、双主题、大字长名、0／50／100%轨道、草稿及禁用／失败状态、持久化与后台恢复；iPhone检查须由用户实际完成并确认。

### Don't

- 不把准备播放56px、窄屏工具gap4px／卡内14px、状态在圆外等 BRIEF 差异默认为新的全局规范；距离和对齐仍待实际渲染验收。
- 不固化日期备注丢失、二级分类未保存、静态统计等模拟缺口；不把专注保存状态链缺失写成已满足。健康撤销名称已于R1.1定点修正。
- 不因图标化删除字段文字或必要确认，也不把日历小触点解释成全稿44px达标。
- 不覆盖旧 DESIGN、修改 `.impeccable` 或创建全局sidecar；不将本次文档核对称为用户验收、正式功能、全量回归或真机通过。
