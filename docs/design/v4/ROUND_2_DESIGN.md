# LifeIndex 4.0 · 第二轮挑战方向「日常调频」

日期：2026-09-28。设计负责人：`/root/design_director`。交付版本：R2.2，已回应独立审核D01–D06；**待独立复查，不自行签收、不冻结设计**。

## 最新授权与本轮结论

用户要求直接设计新版、不考虑历史数据，并明确“大胆尝试，大胆设计”。本轮重新挑战第一轮的A「日序」，不继承旧版布局、组件、导航、历史迁移或备份兼容义务；保留本地优先、零新增费用和真实数据安全。至少完成三轮讨论，仍有关键问题时继续追加，不因达到第三轮自动定稿。

设计推荐将 **D「日常调频」** 作为后续完整状态与实施契约的首选候选。它把录入从首页局部按钮提升为全局动作，把专注发展为有明确运行、暂停和待保存状态的独立空间；视觉用墨紫、奶油与柿橙形成鲜明但连贯的结构。A仍可供对照，但不是已锁定方向。

当前改变的是产品组织方式、操作入口、数字排版、视觉比例与状态，而不只是给A加花纹。R1原型与截图未被替换。

## 与第一轮实质不同的设计

| 决策 | 新结构与用途 | 代价和边界 |
| --- | --- | --- |
| 中央记录动作 | 固定拇指区“＋记录”弹出三种明确类型；任何分区都能两次点按进入首字段 | 增加一次类型选择，但位置恒定，不受列表长度影响；它不是第五个导航页 |
| 日期与标题拥有版面 | 大字号真实日期、紧凑当日范围、明显的标题字重；移除普通后台表格感 | 标题占用空间，因此主要录入独立于内容滚动；不让巨大插画承担功能 |
| 今日概览/今日轨迹 | 两视图均只指2026年9月28日；概览处理当下，轨迹解释当天已保存事实 | 不另建一套隐藏日期过滤，不改变底部领域导航；轨迹不含运行中专注 |
| 不同职责使用不同形状 | 深墨紫习惯区、柿橙专注、浅紫收支；记录仍是可读的纵向条目 | 色块不是健康/财务好坏判断，错误与成功另用明确语义文字 |
| 专注成为空间 | 原创精确椭圆线纹围绕真实读数；暂停改变明确状态，收起保留该状态 | 图形不生成分数、不代表神秘能量；外圈只按实际累计时长显示进度 |
| 可编辑记录独立层级 | 轨迹先打开只读详情，详情中的“编辑”才进入表单；删除独立确认 | 少量额外点击换取读取与修改意图清楚；不把点击记录做成隐式写入 |
| 桌面主动布局 | 左侧分区及记录按钮，右侧行动与记录双列；与手机共享任务语义 | 不把390px画面横向拉伸，触控和鼠标都保留明确入口 |

日常调频的识别来自整体比例、字体、稳定动作与状态，不依靠竞品素材、摄影背景或付费动画组件。保留中国用户熟悉的系统汉字字形，同时用Manrope的数字比例、字重和紧排形成品牌特点。

## 可操作任务与状态

| 路径 | 当前原型行为 |
| --- | --- |
| T1–T3记录 | 中央记录→类型→金额/体重/时长首字段自动获焦，可输入；验证→保存→更新内存→显示明确日期及查看记录；取消返回调用者 |
| T4专注 | 默认25分钟，可选15/45；开始后以真实墙钟累计；暂停不累计，继续接续；收起不改变运行/暂停；结束确认后保存 |
| T5习惯 | 今日显示稳定的前两项，包含一个未完成项；“查看6个习惯”进入完整列表；名称只读查看，独立按钮完成/撤销 |
| T6月报 | 首页或记账进入9月报表；返回恢复来源、账目视图、选定日期及滚动；已保存明细可下钻 |
| 详情/编辑/删除 | 三类记录及专注可查看详情、编辑适用字段、删除确认；输入失败保留，取消脏表单有独立确认 |
| 备份方向 | 可导出本轮合成数据；恢复演示合成预览、明确替换确认和内存替换。实际文件解析及新格式验证尚未完成 |

数据源严格分开：查看不触发写入；正在运行、暂停或待保存的会话不进入“已保存专注”统计；期间标签与实际过滤使用同一日期范围。原型不读取、迁移或删除旧版记录。

### 全局录入与返回契约

- “记录”属于动作，没有当前页选中态；打开类型选择不改变分区、日期、视图或滚动。
- 全局新建默认今天，不能把记账页曾浏览的旧日期带到健康或今天。只有明确的日期记账入口可以继承所选账目日期。
- 两次点按必须到真正可编辑且获焦的字段，而不是只打开类型菜单。
- 取消回原触发控件；保存后即使页面重新渲染，也找到原触发控件的新节点并恢复焦点和滚动。
- 异日保存显示实际日期和“查看记录”；不默默切换原页面正在浏览的日期。

### 新专注状态建议

本轮已交互实现`idle → running ↔ paused → awaiting-save / completed`的内存模型。`running`才按墙钟差值增加累计；暂停保留已累计值；收起只切换页面。保存失败结束计时并保留会话与累计值，不能再显示“正在运行”或“离开不会停止”。

这是新产品取舍，不受旧版状态集合限制。正式模型需要架构负责人冻结：暂停段的持久化、后台恢复、崩溃重启、自然到期、取消、重试幂等、跨日归属、时钟异常和统计规则。本轮不把内存计时正确说成IndexedDB恢复已经通过。

## 视觉与交互规则

| 项目 | 当前规则 |
| --- | --- |
| 浅色 | 奶油画布`#f5f0e8`、墨紫文字`#2d2435`；习惯空间`#2d2638`；柿橙色块`#f18a54`；浅紫收支`#dad1e9` |
| 功能色 | 原鲜橙色不直接承担小字按钮对比度；修订为`#b53b1e`配`#fffaf3`。浅色辅助文字`#706572` |
| 深色 | 画布`#221e29`、内容`#302936`、文字`#f4eee6`；动作`#ffa275`配`#322126`；保持相同形状和信息结构 |
| 字体 | Manrope用于西文与数字；系统汉字；主要数字48–67px、页面标题33–44px、标签12–14px；输入最低16px |
| 形状 | 行动区16px圆角，表单12px，分区导航与全局记录的形状明显不同；不对所有内容统一套卡片 |
| 触摸 | 中央记录至少60×62px；主导航至少53.75×54px；全部功能触点目标44px以上；按下有立即反馈 |
| 动效 | 面板230ms从拇指区进入，确认160ms；按钮120ms按压；暂停状态图形280ms小幅转位与降亮度。无循环背景动画 |
| 减少动态 | `prefers-reduced-motion`移除动画和过渡；控件不依赖动画完成才能操作 |
| 可访问性 | 可见文字和状态图形并存，所有操作保留焦点；金额大字不会清除焦点；模态使用原生dialog及有标签的控件 |

Manrope为官方Google Fonts仓库提供的SIL OFL 1.1免费字体，许可允许随应用嵌入分发；许可证与字体一同保存。[官方许可证](https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt) 当前TTF为164700字节，完整资源预算需计入它，不能只报告JS/CSS。原型不联网加载字体；正式实施可按授权压缩或子集化，但不是本轮悄悄增加构建依赖。

## 独立讨论与本轮修订

审核员先提出三项方向挑战：中央记录的动作身份和返回、两个今日视图的日期含义、跨页面的统一设计规则。本稿用有文字的中央动作、同日视图标签、首页/记账/健康/专注/表单共同的字体和颜色规则回应，等待独立判断其质量。

实际产物预审产生六项问题，均作为一批具体修订处理：

| 编号 | Before | After | 原因与证据 |
| --- | --- | --- | --- |
| R2-D01 日期继承 | 全局表单读取`selectedDate`，浏览旧账日期后可误带给体重/运动 | 全局新建默认今天，仅明确账目日期入口继承；编辑使用记录自己的日期 | 浏览9/14后，今天全局体重表单实际为9/28 |
| R2-D02 期间及最新值 | 月汇总无月份过滤；本周运动包含上周日；最近体重取数组首项且次数固定 | 月份/自然周精确过滤；体重按日期和时刻排序，显示真实次数 | 新增10/1的999元后9月仍1286；9/27运动不计入9/28开始的一周 |
| R2-D03 触点 | 个别文字按钮32/36/40px，取消只有文字宽 | 统一功能触点最低44px，保留清楚间隔 | 320px月历实际最小44.5625×44px；底部各入口也大于44px |
| R2-D04 焦点和返回 | 类型选择更换表单后首字段没获焦；保存渲染使原触点节点失效 | 主字段主动获焦；按语义寻找重新渲染后的同一触发器 | 三类首字段均为`record-amount`且editable；取消及保存回到中央记录 |
| R2-D05 保存失败状态 | `awaiting-save`误套“收起继续计时”“正在进行” | 专注及首页均显示时间已停止、待保存；收起保留待保存 | 专项失败截图和文字观察，不伪装成功或运行 |
| R2-D06 功能色对比度 | 鲜橙按钮配浅字约4.11:1；辅助文字约4.447:1 | 功能色改深橙，辅助文字加深，鲜橙色块仍保留 | 实际色值计算见[色彩及哈希证据](prototype-r2/screens/r2-2-color-and-hashes.json)，相关组合均≥4.5:1 |

根协调已明确支持继续D的独特色块和数字排版，不为修复交互问题退回A；Penpot可编辑视觉板由根协调维护，随功能色变化同步。架构支持新本地库及新状态模型，并要求全局录入恢复原上下文。
