# R2 字体资产

- `Manrope.ttf`：Manrope variable font，来自 [Google Fonts 官方源码](https://github.com/google/fonts/tree/main/ofl/manrope)，2026-09-28下载；164700字节。
- `Manrope-OFL.txt`：随字体分发的 SIL Open Font License 1.1 原文。未修改字体。
- 图标、品牌符号、椭圆线纹由本项目原型代码原创生成，无外部图片素材，无联网字体请求。

字体文件与许可证一起保留。正式包体积和离线缓存需把字体纳入，不以JS/CSS预算排除额外资源。
