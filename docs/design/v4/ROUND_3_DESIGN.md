# R3 完整状态与 R4 动作收敛记录

日期：2026-09-28。作者：设计总监 `/root/design_director`。状态：**完整状态与唯一系统草案已交审核，尚未独立签收。** 当前候选为 D「日常调频」+ R4「整行回应」，不是用 R2 方向通过代替新控件审核。生产实现、部署尚不属于本记录的完成声明。

## 输入与真实讨论

R2 的构图、数字、原创线纹与深浅主题经独立审核通过后，R3 进入健康/习惯/分类/备份/计时与错误状态。根实操发现已用与剩余少一秒、暂停恢复后焦点落 body；审核员提出趋势幅度、局部布局、备份字段与迟到文件读取等具体问题；架构提出独立新库、完整业务备份、跨上下文 generation/revision 和精确日期语义。

用户随后否定传统加号/对号控件。根协调实际做出整行回应、完成纸签、轻推留痕三种可操作比较稿，详见[第四轮](ROUND_4_CONTROLS.md)。设计总监恢复后实际读取三方案源码、动作/布局观测，并逐张查看整行浅色390、深色390、桌面1440和320文字200%截图。选择整行回应进入唯一设计系统：它改变动作范围、回执位置和查看边界，不只是替换图标。纸签保留相邻小动作区，轻推增加发现/误触成本，因此不作为默认产品；不抹去它们的比较证据。

本轮延续 Impeccable 人工手册、Emil 设计工程与 mobile-native 原则；未执行 Impeccable launcher/engine/browser bridge/hooks，未增加工具费用。设计角色本次接续只写两份规范，原型修复/无障碍扫描由根协调负责，避免并发覆盖。

## 系统草案交叉复查补充

审核员对唯一系统给出两项有限合同差异，设计已采纳并交架构：分类保留“重新启用”，需明确 activate 命令；同域 active 规范名冲突时拒绝且保留归档，先改名再试，禁止合并引用。首页进度分子固定为 scheduled∩completed；全天 completedCount 可能含计划外事实，不直接除 scheduledCount，额外事实保留轨迹。新增 A05 的创建后删除再重放 stamp 防护纳入冻结条件。架构交叉确认后补充：名称/备注长度统一 UTF-16 code units；习惯按 createdAt/id 稳定创建顺序，不新增未定义的习惯重排入口；CreationConflict 保留输入，必须明确重新开始，禁止自动刷新 stamp 重提。

根协调实际 axe 扫描发现未选收支文字、分类选中配色的对比问题，改为 ink 与 accent/on-accent；复跑22态报告零违规，仍属作者测试。独立审核另指出深色已完成行浅橙焦点仅1.373:1，根改为明确背景上的内部3px描边：墨紫未完成用 #F7ECD4，纸色已完成用 #2D2435，offset −4px。本系统已写入这两个专用 token，不再将 accent 视为所有表面的焦点颜色，最终解除由审核复查。

收尾复查将动作面左右内边距定为至少8px（当前12px 8px），避免内部焦点环贴近文字；不缩小命中范围。并拆分首页橙色 `focus-entry` 与完整墨紫 `focus-room` 的颜色语义，主文字、次文字、线纹及主控制各有明确 token，避免生产将完整专注页误用首页橙色。两项仅澄清当前稳定方案，不新增风格。
