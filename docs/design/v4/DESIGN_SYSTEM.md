# LifeIndex 4.0 设计系统

日期：2026-09-28。负责人：设计总监 `/root/design_director`。状态：**唯一实施候选 v1，提交独立审核；未自行冻结。** 本规范合并 D「日常调频」的视觉系统、R3 完整状态与 R4「整行回应」。原型用于验证布局与交互，数据行为以[架构 v3](ARCHITECTURE.md)的唯一契约为准。用户最新对加号、对号式控件的否定优先于 R1/R2 旧稿；纸签与轻推保留为比较证据，不进入默认产品。

## 1. 产品与信息结构

LifeIndex 是本机生活记录与回看工具。设计围绕清楚的录入、当天可执行的动作、真实的记录与可恢复的状态。品质愿景不转写为“超过市场 80%”的未经验证结论。不引入账号、云服务、分析追踪或收费资源；不要求旧库迁移，也不删除旧库。

四个同级分区为今天、健康、专注、记账；设置为有齿轮和“设置”文字的明确入口。手机底部导航与桌面侧栏共享这套信息结构。全局“留一笔”是动作，不是第五个页面或“全部功能”入口。手机与桌面显示名称统一为“留一笔”，可访问名称为“留一笔，选择记录类型”。

| 页面 | 内容与顺序 | 主要行为 |
| --- | --- | --- |
| 今天·概览 | 当地日期/简短页题 → 概览/轨迹 → 活动专注状态（存在时）→ 今日计划习惯的前 2 项 → 专注与今日收支区 → 最近录入 3 项 | 全局录入始终可达；习惯一触完成/撤销；进入专注；打开当月报表；所有记录可查看 |
| 今天·轨迹 | 明确当天范围；有实际时刻的事实与“当日记录·未记录具体时刻”分组 | 展示交易、体重、运动、习惯完成、已完成专注；详情零写入；运行会话另列 |
| 健康 | 最近体重/目标 → 趋势与完整历史 → 本周运动/历史 → 全部习惯 | 记录、目标设定、历史详情与修改；创建和管理习惯 |
| 专注 | 当前状态 → 会话标题/时间 → 唯一主控制 → 结束/收起 → 今日已保存汇总与完整历史入口 | 15/25/45 分钟，默认 25；开始无需标题；真实暂停、恢复、结束、重试或明确放弃 |
| 记账 | 所选月份 → 收支摘要 → 本月流水/按日查看 → 对应明细 | 记录支出或收入；按日查看；月报；明细详情 |
| 月报 | 明确所选月份 → 支出/收入/结余 → 按分类去向与对应明细 | 更换月份；返回原页面、视图、月/日、筛选、滚动和语义焦点 |
| 设置 | 主题（跟随系统/浅色/深色）→ 分类 → 数据说明/导出/恢复 | 所有偏好和数据动作有明确反馈；恢复先验证、后预览、再确认 |

首页预览的数量不作为统计分母。习惯展示按稳定创建顺序（createdAt/id）截取当日有效计划，不通过移动完成项制造“全完成”；完整列表保留暂停与非计划项。全局录入不随长列表消失。没有记录时不植入演示事项、虚构活动或自动生成生活解释。

## 2. 动作、完成与查看

### R4 整行回应

习惯行由两个相邻而独立的原生按钮组成，禁止嵌套交互元素：

- **动作面**占可用行宽；左右内边距至少 8px、上下默认 12px（`padding: 12px 8px`），文字不得贴住内部焦点环，完整命中范围保持不变；标题与回执属于同一完成按钮。未完成文案“今天做过了？点按记下”，完成后“今天已记下 · 点按撤销”。显式 `aria-pressed` 与可访问名称“完成{名称}／撤销完成{名称}”。鼠标、触摸、Enter、Space 均完成同一 desired 状态命令。
- **详情**至少 44×44，文字始终可见，accessible name“查看{名称}详情”。查看不完成、不撤销、不暂停；详情内的修改、暂停、删除再以明确动作触发。
- 未完成为墨紫底与暖白字；完成后整行出现浅米色实底和深色文字。不使用加号、对号、空心仿复选框作为完成状态。状态既有文字也有色彩。
- 今日工作区的进度严格为 `scheduledCompletedCount = |scheduled ∩ completed|` 除以 `scheduledCount`；当天全部 `completedCount` 包含计划外事实，不得直接作为这个分子。健康完整列表同时显示“每天／周一至周五／每周…／已暂停”和今天是否为非计划日，不能让完成回执吞掉计划状态。暂停/计划外仍可手动补记；副文案明确，今日计划分母不包含它们，但真实完成仍进入轨迹。
- 点击后焦点留在同一语义动作位；只有它被底栏遮挡或超出可视范围时才滚到可见处。成功不弹祝贺层、不强行跳页；失败保留原状态，行内或临近反馈“这次没有记下，请重试”。正式实现等待真实命令成功后确认完成。

全局“留一笔”采用原创笔形 SVG 与文字，打开三选一：记一笔、记体重、记运动；再进入首字段已获焦的编辑器。至可编辑界面不超过两次点按。领域内明确的“记体重”“记运动”“记一笔”可直接进入对应编辑器。取消选择器回原来源，不能把打开选择器算作已进入编辑器。

其他动作以动词为主：保存记录、保存修改、开始专注、暂停一下、继续专注、重试保存、关闭、保留记录、确认删除。保存不以勾选图标证明成功，新增不依赖加号；笔形图标只辅助书写语义。不要把所有图标全局替换成树叶：R4 原型里的临时图标别名是比较稿机制，生产组件使用明确的动作键。

## 4. 字体、布局与形状

拉丁字母与数字采用本地 Manrope 可变字体（200–800）；正文/汉字使用系统中文字体。来源与 OFL 1.1 许可见 `prototype-r2/assets/README.md`、`Manrope-OFL.txt`。仅保留一份生产字体资源；使用 `font-display: swap`，不得依赖在线字体请求。数字使用 tabular-nums，负号、货币和单位显式保留。

| 层级 | 默认字号 | 行高/字重 | 规则 |
| --- | --- | --- | --- |
| 首页陈述 | 2.75rem，手机 2.25rem | 1.2 / 650–700 | 自动换行，不截断；重复长标题可减少文案而非缩字 |
| 页面标题 | 2.25rem，手机 2rem | 1.25 / 650–700 | 单页唯一 h1 |
| 领域数字 | 3–4rem | 1.15 / 550–650 | 大字压力下独占行，不裁切时间或金额 |
| 章节标题 | 1–1.125rem | 1.5 / 600 | h2/h3 层次连续 |
| 正文/行标题 | 0.9375–1rem | 1.5–1.7 / 400–600 | 长名称可多行 |
| 辅助/回执 | 0.75–0.8125rem | 1.5–1.7 / 400–600 | 默认不小于 12px；重要动作不缩成脚注 |
| 输入字段 | ≥1rem | 1.5 | iOS 不因小字号自动放大；错误不只靠 placeholder |

使用 rem 和内容驱动高度，支持 200% 文字。空间基值为 4、8、12、16、20、24、32、40、48；手机水平边距默认 24，320 宽降至 16；桌面内容最大 1360、侧栏约 216、主区边距 46。这些宽度是上限/默认，不是强迫内容塞入固定格子的硬尺寸。

圆角分层：小字段/动作 8–12；习惯区 14；领域空间 18–24；移动 Sheet 顶角 22–24。完成行约 10。留一笔采用不对称圆角 `16 16 22 8`，同一动作在桌面保留相同几何语气。阴影只用于浮动底栏、Sheet 与确认，不给所有容器套同一悬浮卡片。分隔线、留白和排版承担普通内容层次。

## 5. 响应与可访问性

- 320/390/430 手机为单列主内容；专注/收支块仅在各自可容纳至少 10rem 内容宽时并列。768 视内容选择；桌面以侧栏与两列阅读区展开，共享相同任务顺序。
- 底部导航正常为四分区加中央“留一笔”。**当内容宽度不足（窄屏或文字放大）时，留一笔独立上一行，四分区等宽下一行。** 保留所有文字、不缩放用户字体、不将动作隐藏进更多菜单。底栏高度由实际内容决定，主内容 padding、scroll-padding 与焦点可视判断同步使用其真实高度及安全区。
- 触点至少 44×44 CSS px；邻接动作保留空间，不以重叠透明 hitbox 扩大日历。320 日历七列使用可用整宽，日期含明确可访问名称；文本放大允许格子增高。默认相邻“完成/详情”分别可辨认。
- 手机 Shell 使用 `100dvh`、安全区与 `interactive-widget=resizes-content`；输入键盘出现时表单内容能滚动，保存动作可达。Sheet 最高 `calc(100dvh - safe area)`，内部滚动而不是裁去按钮。
- 导航有当前位置，主内容有跳转入口；键盘顺序与阅读顺序一致。所有输入有真实 label、说明和错误关联，错误摘要获焦但不清空输入。模态打开后焦点在主字段或合适标题，Tab 留在当前模态；关闭/保存返回来源语义焦点，来源消失回稳定列表标题或新建入口。
- `:focus-visible` 始终可见，3px 左右边线及适当外距；深浅/完成底分别验证。焦点不被底栏或粘性页脚覆盖。不要为了截图“漂亮”移除合法焦点。
- 图表有可见数值摘要、单位、范围及历史列表替代。颜色不是唯一分类依据。长标题/金额/错误允许换行，图表和时间不靠 overflow:hidden 掩盖内容。
- 自动扫描要求 axe 无 serious/critical；仍需人工复查焦点、图形意义、文字放大与触控。浏览器 WebKit 不代表物理 iPhone，未获得真机确认不得声明完成真机验证。

## 6. 图标与品牌资产

业务实体可持久化的 `iconKey` 唯一枚举为：

```ts
type EntityIconKey =
  | 'today' | 'health' | 'focus' | 'finance' | 'activity' | 'weight'
  | 'leaf' | 'book' | 'cup' | 'bag' | 'arrow'
```

图标选择器按这 11 项提供名称与图形；它们使用 24×24 viewBox、1.7px 描边、圆头圆角、无渐变、无外链。默认显示 20–24，次级 16–18；SVG 为装饰时 aria-hidden，由按钮/文本提供名称。业务未知键由 schema 拒绝，不能静默换成任意图标。UI 专用图标另用 `write/settings/play/pause/back/close/download/upload/sun/shield`，不进入实体枚举。日历 glyph 不含完成勾选。主题/删除/状态也不得仅靠未命名图标让人猜。

笔形 `write` 几何（24×24，统一描边）：`M15 4L20 9; M4 20L9 19L21 7A2.1 2.1 0 0 0 16 2L4 14Z; M12 20H20`。它辅助“留一笔”，不单独替代文字。

品牌标记是倾斜的圆角种子外形与内轮廓，延续已审核 D 页头；不是完成按钮。生产 SVG 统一以以下几何为源，避免 CSS 和 PNG 各自重新画：

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <g transform="rotate(-15 32 32)">
    <path fill="#B53B1E" d="M32 8A24 24 0 0 1 56 32V42Q56 56 42 56H32A24 24 0 1 1 32 8Z"/>
    <path fill="none" stroke="#FFFAF3" stroke-width="4" stroke-linejoin="round"
      d="M32 22A10 10 0 0 1 42 32V38Q42 42 38 42H32A10 10 0 1 1 32 22Z"/>
  </g>
</svg>
```

应用内标记默认 24、最小 20 CSS px，左右净空至少其宽的 1/4；字标使用 Manrope 800，不拉伸。深主题填充换 accent/on-accent 对；单色场景保持内轮廓负形，不加渐变。16px favicon 可省略旋转并使轮廓按像素对齐，仍保留同一外形与负形。

PWA 192/512、maskable 512、Apple touch 180、favicon SVG/16/32 使用同一源。图形整体位于 maskable 中央 80% 安全区，画布为浅 canvas；静态安装图标不依赖页面主题或外部字体。更新 manifest/name、图标链接、离线资产清单，不能留下旧 Ocean 标记。根协调生成文件与离线 PNG，本规范不声称资产已生成或部署。

专注原创线纹使用 160×160 SVG，12 个椭圆围绕中心 80/80，每次旋转 15°，半轴 64/25，细线 1.1；大专注空间可用 18 个椭圆、每次 10°。线纹仅为装饰，aria-hidden，不持续旋转、不表示虚构进度。进度圆仅反映同一真实计时快照，数字必须完整可读。

## 7. 页面与数据语义

| 领域 | 唯一体验规则 |
| --- | --- |
| 交易/体重/运动日期 | 只输入日期，day 精度；显示日期或“日期记录”，不把 createdAt/午夜冒充消费、测量或运动分钟。补记过去日允许；新事实不能晚于设备今天；打开表单跨午夜不自动改所选日 |
| 今日轨迹 | 实际时刻的习惯完成与专注独立排序；日期记录分组，不按伪时刻穿插。专注按开始日归属，跨日时显示开始日期说明；仅 completed 进入完成统计 |
| 体重 | 最近值先按事实日期，再按 createdAt/id；趋势每自然日取“当日最后录入”，不称最后测量。所有同日记录留在历史；少于两天不连线；可见起终、变化 kg、日期范围。目标只显示数值距离 |
| 运动 | 类型、整数分钟、轻松/适中/高强度、日期和可选备注；本周固定周一至周日。历史按日期分组；编辑/删除同步真实汇总 |
| 习惯 | 每周重复至少一天，可自定义 1–7；计划修改/暂停/恢复从今天生效，不回推历史缺勤；补记和撤销为明确动作；暂停保留完成事实；删除确认明确连同完成记录范围 |
| 分类 | 支出/收入/运动/专注四域单层。新建/改名/选择图标/排序/归档/启用；同域 active 规范名唯一。重新启用调用明确 activate 命令；若与同域 active 规范名冲突，保留归档并提示先改名，允许编辑归档名称后再试，不自动合并或覆盖引用。使用中删除引导归档，未使用才可删除；历史稳定引用。编辑保留原归档类，但不能新选其他归档类 |
| 记账日历/月报 | 标题、摘要、图表和列表使用同一选月；日期查看只改领域浏览，不污染全局新建默认今天。仅明确日期内的记一笔继承所选日；异日保存给实际日期和“查看记录”，不偷偷切换原浏览日 |
| 专注 | 默认自由专注 25 分钟，可选 15/45；running 真运行，paused 停累积，收起只导航。结束确认前仍按原状态；确认时捕获固定终点。待保存显示“时间已停止，等待保存”，只允许重试/明确放弃，不能继续计时 |
| 计时显示 | 一份 elapsedMs 快照；已用=floor(elapsedMs/1000)，剩余=目标整秒−已用。底层毫秒累计，不在每次暂停时截去余量。发生时钟异常给说明和恢复路径，不能写成零时长完成 |

输入与备份共享边界：人民币 1–9,999,999,999 分，金额最多两位小数；体重/目标 1,000–1,000,000 克（1–1,000kg，最多三位小数）；运动 1–1,440 整数分钟；分类名 1–30、习惯名 1–40、专注名 1–80、备注最多 1,000 字符。名称/备注长度按 UTF-16 code units 计数，与原生 maxlength 一致；提示与服务校验采用同一边界。首字段：金额/体重/运动分钟。字段名称、单位、范围错误具体，保留输入；不要在用户每输入一位时抢焦点或重新格式化光标。

## 8. 组件与状态契约

| 组件/流程 | 状态与恢复 |
| --- | --- |
| Region/QueryFeedback | loading 用稳定骨架和读取说明；empty 才展示真实零值/新建入口；failed 明说暂时读不到并允许局部重试，不显示假 0；旧快照注明尚未更新 |
| RecordRow/Details | 行打开只读详情；显式编辑/删除；删除确认标明对象和范围，失败保留详情。对象不存在显示已变化与返回来源，不创建占位记录 |
| Composer/Editor | 保存/取消恢复原分区、模式、日期/月、筛选、滚动和有效焦点；直接链接无来源时回相应领域。保存成功回执含真实日期和查看入口 |
| Field/Validation | label、单位、可选说明、关联错误；校验失败保留草稿。输入组件不自行写库 |
| Saving | 同步防重+服务幂等；命令捕获数据代次/修订 stamp，创建后删除再重放旧创建不能复活实体；当前提交控件禁用并显示正在保存；保存中不能以关闭/更新丢弃正在提交状态；失败重新可编辑、原输入完整 |
| DirtyExit/Confirmation | 未保存离开→继续编辑/放弃修改；取消返回原草稿。确认层独立焦点范围，无动画等待；危险操作不默认冒充成功 |
| BackupFile/Preview | 选文件不写库；校验错误说明可重选；完整校验后显示八业务集合数量、版本、导出时间、目标替换数量、源/目标未结束专注状态与影响。取消保留库；确认才原子替换 |
| RestoreConflict | 预览绑定 generation/revision 和 15 分钟 TTL；过期/别处写入拒绝替换，提示“本机记录已变化，请重新检查备份”，允许重新预览/取消。不能延用旧确认覆盖新记录 |
| CreationConflict | 草稿打开后其他上下文写入，或旧创建成功后又被删除，expectedRevision 冲突时保留输入；提示检查最新内容后明确重新开始，可复制草稿。不自动刷新 stamp 重提，不让旧创建复活已删除实体 |
| DraftConflict | 恢复后旧草稿输入保留；说明“数据已恢复，这份草稿属于恢复前的数据，请重新打开记录”；可复制后关闭，不能自动变更 generation 重试写入 |
| RestoreBusy/Failure | 提交中不能取消；失败整库不变，保留有效候选可重试。迟到文件读取被取消/选择 token 丢弃，不能重开旧预览 |
| FocusPending | prepare 失败的本地意图明确尚未持久化、启用退出保护；durable pending 重开后仍待保存。两者都不进入完成统计、不给运行文案 |
| Shell/PWA | 离线：本机可用；SW失败：离线尚未就绪；更新准备好：稍后/立即更新。脏表单、写入或恢复中禁用更新并解释先完成当前动作。状态条占正常布局，不浮盖主要入口 |
| Toast/InlineStatus | 成功只在命令返回后呈现；可选查看记录。短暂回执不是唯一失败说明；错误留在相关区域直到恢复。屏幕阅读器使用合适 status/alert，计时不每秒打断朗读 |

备份范围包括八业务集合及运行/暂停/待保存专注；“仅已保存”只限制完成统计。恢复运行会话按原起点与设备时间追平封顶，暂停保持暂停，pending 保持固定意图；预览不推进导入状态。目标存在未结束会话时明确会被替换，允许取消返回专注，不强迫提前结束。生产文件 50MiB 上限与 15 分钟 TTL 以架构为准；原型自己的合成格式和 2MB 限额不是生产格式。

共享组件只处理显示、语义和焦点；领域 controller 处理状态，服务处理验证/持久化。FormSession、ReturnContext、GlobalComposer 与 FocusRuntimeController 由架构声明的 owner 维护。禁止用大量布尔参数把所有领域、详情、历史、编辑塞入一个组件。全局渲染不能使局部输入或恢复/暂停焦点丢失。

## 9. 动效与输入时序

最新 R4 使用高频面板立即打开/关闭，所有输入方式一致，不再继承 R2 的 230ms 入场动画。键盘尤其不可等待动画；主字段与首个动作立即可用，不以 animationend 解锁。正常指针只保留 120ms、`cubic-bezier(.23,1,.32,1)` 的小幅按压 transform（约 0.97）；背景、完成颜色直接呈现。大内容动作面若缩放影响文字清晰可只在按下时轻微反馈，不引入慢回弹。

reduced-motion 关闭非必要 transition/animation，保留清楚即时状态；键盘 focus-visible 直接呈现。退出即时完成，不等待闭合动画；快速打开/关闭/再打开不排队旧动效。图形不持续旋转，timer 只更新必要文字/进度，不驱动全页重挂载。原型轻推手势不进入默认产品，无需为本次默认方案增加动画/手势库。

## 10. 交付与冻结条件

唯一实施目标是本规范的 D + 整行回应 + 留一笔。`prototype-r4/?controls=surface` 为当前视觉/动作载体，R3 是其共享状态底稿；R1/R2/另两种 R4 方案作为历史证据，不再并行生产。

冻结前只核对有限条件：R3 架构 A01–A05 与视觉 D01–D05 有独立解除记录；R4 整行/详情/失败/撤销和两步录入证据通过；健康计划副文案、窄屏大字两层导航已实际修订并复查；设计 tokens/图标/日期/边界与架构唯一契约一致；完整状态都有原型或明确合同；独立审核签收。作者自测、轮次达到、目录齐全都不等于通过。

生产验收继续覆盖真实 IndexedDB、并发恢复、离线/PWA更新、全页面深浅/文字放大、性能预算、构建/测试/线上部署。设计阶段不预先宣称这些已经完成。性能门槛、统计口径与样本方式引用[测试策略](../../testing/v4/TEST_STRATEGY.md)，不另设一组矛盾数字。
