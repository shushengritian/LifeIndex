## 三个方向的共同评价标准

| 维度 | 本轮解除疑问所需证据 | 拒收条件 |
| --- | --- | --- |
| 实质差异 | 三个方向在首页信息优先级、导航或浏览结构上有可见差异；以相同合成记录、390px 首页和录入入口对照 | 同一组件改三种颜色，或只有形容词没有实际稿件 |
| 高频行动 | 六项新版任务逐项映射；记一笔、体重、运动等高频输入不超过两次点按进入编辑；记录是否需滚动及操作所在区域 | 首屏无明确录入入口、动作承诺和实际行为不一致，或改动后再挑选有利任务 |
| 导航发现性 | 顶层分区、设置、返回来源和深层落点清楚；若取消设置底栏，给出可见名称和固定寻路脚本 | 只靠陌生图标、手势或“用户会知道”；必须经过不相关功能才能找到备份 |
| 读取与写入 | 记录详情、录入、打卡、删除视觉语义不同；展示至少一个录入流程和一个只读下钻 | 卡片既可查看又会立即写入，却没有独立触点或说明 |
| 真实数据 | 摘要/时间线注明来源及周期；加载、空、失败分开；运行中专注不冒充已保存会话 | 虚构生活综合分、虚构趋势、把缺失算零或把无记录写成表现差 |
| 视觉组织 | 同一数据量下查看层级、文字尺寸、留白用途、长标题和按钮体系；不能仅看空屏大留白 | 大标题与装饰挤压任务；关键数值依赖微小字；不同页面像独立模板 |
| 移动与无障碍 | 320px 方案、44px 关键触点、16px 输入字、文字放大、键盘/焦点、语义状态的计划；第二轮提交实际验证 | 以隐藏/裁切内容解决溢出；只有颜色传达状态；手势无可点击替代 |
| 状态与安全 | 各方向说明空、失败、忙碌、未保存、专注恢复、备份替换的表达；后续以状态矩阵验收 | 用成功画面替代全部状态；错误清空草稿；恢复流程省略预览和确认 |

本轮方向选择不能宣称完成视觉、浏览器或真机验收。真实 iPhone 仍待用户执行并确认，不作为本次自主浏览器发布的等待前提。

新版任务由总协调维护：T1 新增支出并保存；T2 记录体重；T3 记录运动；T4 开始默认时长专注及清楚的离开/返回状态；T5 今日习惯完成/撤销；T6 查看当月支出报表并返回浏览上下文。当前原型T4采用收起后时间持续运行；若后续新增真实暂停，需另行明确累计、恢复和保存规则，不能用“收起”冒充暂停。
