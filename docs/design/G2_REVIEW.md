## 本轮提出的交互方案

- 健康首页保留四组摘要和记录入口；体重/运动有完整历史页，习惯有独立统计详情。不再把历史全堆在首页，也不增加一级导航。
- 今天“记一笔”直接打开记录表单，保存/取消回来源；记账首页日历选日后新增继承该日。
- 短表单统一底部面板；取消、关闭和 Escape 共用脏输入规则，默认不靠背景点击或拖拽关闭。
- 已开始专注可以切页继续；未提交输入离开需明确放弃。专注不新增暂停。
- 危险操作说明对象和后果，避免含糊的“确定”。恢复仍先校验、预览，再整库替换。
- 设置分为分类、外观、数据与安全、其他；分类默认折叠。深浅主题视觉尚未定稿。

## 原型实现边界

只使用内存中的合成数据，无 IndexedDB/localStorage/cookie/SW；CSP 禁止网络连接，页面不加载外部资产。刷新会恢复初始演示。日志只包含固定事件类别，不包含输入。

可交互：五主页面、日历固定月份选日、代表性新增/编辑/删除、保存失败模拟和重试、放弃输入、40 条体重历史、习惯打卡撤销/详情、专注开始/结束确认、恢复预览确认。确认恢复只展示流程，明确不执行恢复。

未完整实现且界面明确标注：全字段表单、跨月切换、动态金额汇总/热力图计算、习惯创建与管理、完整戒烟事件与管理、专注自定义时长/真实后台计时、文件保存/恢复、更新/离线/URL Action。它们的流程和异常状态在规格中定义，G4 全量原型/G5 产品测试再覆盖。

本稿是灰阶线框，不作为最终按钮图标、字体、配色、动画、双主题或屏幕安全区的视觉验收。模态使用原生 HTML dialog 承载自定义内容，不调用浏览器 alert/confirm/prompt。
