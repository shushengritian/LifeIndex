## 实现

记录行使用分隔线和整行编辑按钮，长备注列表截断但编辑保持原文；删除 SVG 具有可访问名称且触点 44px。当前是通用账目图标，分类专属 42 图标接入未完成。表单底部操作区粘性定位，保存到不同日期后日历不跳动，显式“查看记录”才切换。金额/日期/类别仍由仓储验证。

原生日期选择器可能已改变 DOM 值但未发出 change。提交改从命名控件 FormData 读取实际值，同时监听 input/change 更新草稿状态。该边界在浏览器发现并复验，另有模拟延迟事件的单元环境测试。
