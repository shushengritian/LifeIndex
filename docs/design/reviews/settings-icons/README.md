# 手机反馈修订验证 — 2026-09-20

对应 ADR-0018。以下为本地候选验证记录；用户随后授权发布 2.2.2，当前发布状态见 [发布记录](../../../releases/v2.2.2.md)。

## 已完成

- 新 Ocean App 图标（SVG 几何源、五种 PNG、离线生成脚本），已目视检查 512px 输出。
- 60 个分类图标、11 组；新增旅游住宿、家庭教育、生活服务。所有图标的 V4 导出与恢复数据相等；不迁移或改写已有记录。旧程序不支持含新图标的备份。
- 设置行、分类管理入口及主题选项 14px 圆角高亮；统一图标内边距，不改动二级分类的纯名称交互。
- 导航和设置内部链接抑制 contextmenu/touch-callout；Sheet 和 ConfirmDialog 返回焦点不主动滚动页面。

## 自动化证据

- TypeScript、ESLint、Prettier、生产构建与 git diff --check 通过。
- 单元/集成：45 文件、207 项通过（新增全部图标备份往返）。
- Chromium/WebKit 全量：73 通过、1 项原有 WebKit 离线全页重载跳过。
- 最后一处分类管理入口圆角/对齐补齐后重新构建：设置恢复及紧凑分类两份测试共 10 项通过（双引擎）。
- 新增测试覆盖：模拟 contextmenu 被阻止、文件选择空输入/cancel、分类编辑二次确认的取消及放弃、退出后背景非 inert、底部五项导航在视口内且可切换、深浅主题圆角。
