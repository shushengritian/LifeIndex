# G4 C2 戒烟验证

2026-09-19，浏览器本地合成原型。未触碰 IndexedDB、备份、生产代码和线上部署；不是真实 iPhone 测试。

## 实测路径

- 初始 5 个完整日、覆盖 8/12、估算 75 元。今日快照后完整日与估算不变，覆盖变为 9/12。
- 保存吸烟与今日快照冲突时出现明确确认；模拟失败保留快照/表单；重试成功撤销快照并显示吸烟事件。删除后回到尚未确认，不自动生成完整日。
- 确认 9 月 17 日全天未吸烟，完整日 5→6、估算 75→90 元；已有烟瘾事件不等于吸烟，不阻断合法确认。
- 烟瘾可启动小休息、选“还想抽”与压力诱因后立即保存，无需等计时结束。
- 隐藏后健康不再出现戒烟；设置“其他”可进入管理。结束计划显示已结束、保留历史和新建入口。
- 未来样本显示准备中；取消后显示已取消，随后可用演示当前时间开始新计划，没有空区间重叠误拦截。
- 无计划样本进入开始表单，只填估算的日均支数被拦截；完整填写 10/20/30 后保存，覆盖 0/1、完整日 0，未把部分日算作全天。
- 月历可展开；320/430px 页面 clientWidth 与 scrollWidth 相等。390px 深浅首屏已截图检查。

## 可复现检查

`node docs/design/reviews/g4-c2/check-cessation.cjs` 加载实际控制器，断言完整日边界、快照分离、估算、过去快照待确认、冲突撤销、移动/删除不恢复、稳定编辑 ID、未来/取消/结束状态、刚开始部分日覆盖。C1 专注控制器测试再次通过。

语法检查 `node --check docs/design/prototypes/g4-cessation.js`、`g4-app.js` 及 `git diff --check` 通过。

## 边界与待办

固定 Asia/Shanghai、2026-09-18 12:00；纯函数采用这一时区的固定偏移，不适用于 DST 或跨时区生产替换。原型没有持久化、真实设备后台恢复或数据库事务；不将模拟成功称为这些能力通过。所有错误/长文/读屏/键盘/200% 放大组合仍在 D；3 分钟完整等待、撤销确认、原因修改和多计划历史选择尚未逐条浏览器验收。烟瘾感受默认首项可修改，最终交互仍待用户审稿。

状态样本入口通过固定非个人参数选择：`cessation=empty`、`future`、`ended`。新开样本会创建独立内存，刷新重置，不能作为生产数据测试。
