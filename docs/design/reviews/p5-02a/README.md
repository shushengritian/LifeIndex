# P5-02a · 记账确认与写入保护

2026-09-19，正式源码本地开发服务 4180，非隔离原型。未提交/发布，数据库仍 V3。

实现：共用原生 ConfirmDialog（portal、明确危险文案、安全取消优先、busy 拦截 Escape）；记账放弃与删除采用应用内确认。失败不关闭删除确认；保存 ref 同步锁、字段和取消按钮禁用、草稿保留；保存/删除反馈仅发生在 repository 成功之后。Sheet Tab 首尾循环，原生确认开启时不抢键盘。无金额、备注或记录 ID 日志。

验证：

- 新增 integration 3 用例：继续填写保留草稿/显式放弃不写库；取消删除与注入删除失败保留记录/重试成功；挂起保存锁定表单/失败解锁保留草稿。
- 全量 25 文件 143 测试通过；类型检查与修改 TS/TSX ESLint 通过。
- 浏览器实际合成数据：12.50 餐饮创建，取消删除后仍存在，确认删除后显示成功。仅删除本次创建的测试记录，不操作用户真实数据。
- Escape 关闭放弃确认，回到表单取消按钮且金额未变；保存按钮 Tab 回到首个支出按钮。
- 确认框浅/深、320/390/430px 共 6 组无页面或弹窗横向溢出。[深色截图](discard-dark.png)为危险文字着色补充前版本，布局与交互不变。

测试环境对 dialog 做 open/close 最小模拟，不能证明原生模态；原生行为由上述浏览器路径补验。未真机、未读屏、未 200% 放大、未完整 E2E，其他模块的默认确认框与站内导航草稿协议仍待迁移。记账完整新布局尚未实现，本批不是 P5-02 完成声明。
