# 分类管理 · 一级进入二级

2026-09-19，按用户反馈替代上一轮“一级/二级混排＋父级下拉”交互。仅修改 G4 设计原型。

## 参考与取舍

- [Red Money 官方说明](https://redmoney.app/faq)：在分类编辑上下文中的 Subcategories 区域新增子分类。参考“先定位父分类再新增”的关系，不复制其长按入口或删除交易逻辑。
- [WeMoney 官方说明](https://intercom.help/wemoney/en/articles/8289589-how-do-i-create-custom-categories)：分类命名、图标与颜色字段。用于确认编辑内容，不作为二级分类导航的证据。
- MoneyWiz 搜索结果提及展开父分类，但本轮官方页面直接抓取返回404，不据此声称复核了当前界面。
- Impeccable clarify 手动参考用于明确动作/上下文、减少重复选择，未运行引擎。

## 新交互

1. 设置分类入口进入一级列表，仅显示该收支类型的根分类，每行展示二级数量和直接记录数。
2. 点一级进入该父级的二级列表，右上编辑一级名称/图标或归档；二级标题旁“＋新增二级分类”。
3. 二级编辑表单固定展示所属一级，只输入名字、选图标；颜色可选折叠，默认继承一级颜色。无父级下拉，无第三级入口。
4. 保存成功回当前二级列表；失败保留输入，取消走已有草稿保护；返回一级恢复原筛选、滚动和行焦点。
5. 使用中/已归档筛选只作用于当前层；父级归档时禁止新增子级，但历史与子级管理保留。恢复子级而父级仍归档时，仍留在已归档列表并说明需恢复父级。
6. 专注/运动仍是平级分类，退出和换组重置记账下钻上下文。

## 已检查

- 浏览器：根级不混入早餐/正餐；进入餐饮，新建下午茶并选饮品图标；失败→保留→重试成功；再次编辑图标为 coffee，父级下拉数量为0。
- 浏览器：父级归档使子级全部进入归档列表；恢复后返回根级仍聚焦餐饮。单独归档早餐、再归档餐饮、随后恢复早餐时，修正为留在归档列表而非跳到空使用中列表。
