# P5-02c · 导航草稿保护验证

2026-09-19；正式本地应用 http://127.0.0.1:4180/；非线上、非 iPhone 真机。

## 实现

- 站内切换模块或返回：已登记未保存输入弹出“离开并放弃输入？”，默认焦点在“留在当前页”。
- 记账保存/删除期间：拒绝导航，不提供放弃写入，不在完成后自动跳走。
- 受保护时禁用更新并在更新命令入口再次检查；刷新/关闭仅请求系统卸载提示。
- Sheet 原触发按钮已不在 DOM 时回到主内容焦点。

## 证据

- 新增 navigationGuard 测试 5 项：链接取消/放弃、POP、busy、clean、卸载/更新命令保护；App 导航加入 StrictMode 覆盖。
- Vitest 全量 26 文件/150 项通过；tsc、改动文件 ESLint、Vite/PWA 构建通过。现有 inlineDynamicImports 废弃警告仍存在，无依赖修改。
- 浏览器输入合成专注标题后点击健康，出现确认；留下后输入原样保留；再次点击健康并确认放弃，最终进入健康且确认消失。未提交任何专注记录。
