# 3.1.0 生产实现检查

2026-09-21。预览入口 `preview.html` 嵌入真实 React 页面，使用独立 4193 来源与合成数据；外层验收工具的滚动条不是应用内滚动条。

本次浏览器观察：320×568 深色记账编辑器头尾可见，备注可聚焦访问，关闭后导航恢复；320×568 专注主操作在计时区；390×844 浅色报表显示分类条与每日趋势；430×568 浅色体重编辑器有固定关闭和保存；320×568 分类编辑草稿关闭弹出确认，放弃后五个导航入口恢复。

自动化矩阵由 Chromium 与模拟 iPhone WebKit 验证：深浅主题、320 窄屏、弹层键盘焦点、正常滚动且无网页滚动条、导航恢复、分类、备份、健康历史与离线。最终计数和云端证据以 [发布记录](../../../releases/v3.1.0.md) 为准。

目录内 editor/report PNG 是此前首批实施时的历史截图，不声称全量最新截图。本次真实浏览器检查未把所有组合截图归档；不把 JSDOM、Chromium 或模拟 WebKit 当成物理 iPhone。

仍待用户：iOS 键盘、安全区、系统长按菜单/文件选择器、主屏幕更新、后台及锁屏专注、VoiceOver 和离线重启。
