# G4 D1 · 交付状态与跨页尺寸证据

日期：2026-09-19。结论：D1 独立交付状态原型和下列检查完成；D2 未完成，G4 未整体验收。

## 产物与边界

- [整体审稿板](../../prototypes/g4-review.html#delivery)、[独立交付状态](../../prototypes/g4-states.html)。主应用关于/设置文案同步去掉过时的“第一批”。
- Impeccable harden 手动参考用于失败恢复、状态说明、禁用与焦点设计；未运行引擎或安装钩子。Ocean 视觉方向不变。
- 固定合成金额和备注，不解析外部 Action，不执行记账、不注册 Service Worker、不访问数据库、不修改生产代码或发布。
- 成功/去重/离线均是交互状态模拟。原型刷新重置，不证明真实离线可用、更新安全、跨刷新去重或恢复持久性。

## 本轮已检查

| 项目 | 证据与结果 |
| --- | --- |
| 草稿阻止更新 | 浏览器勾选草稿，更新按钮禁用，显示先保存/放弃说明 |
| 保存中与离线阻止更新 | 实际 reducer 断言通过；离线浏览器页面确认按钮禁用 |
| 更新失败与重试 | 浏览器触发失败，显示继续旧版本/无需清数据，重试进入演示完成状态 |
| 无效 Action | 浏览器切换校验失败，禁用确认并解释未写入 |
| Action 失败重试与去重 | 浏览器失败→重试成功→重新打开同一示例，显示已处理且没有确认入口 |
| 取消、稍后、忙碌互斥 | `check-delivery.cjs` 对实际 reducer 的断言通过；非真实存储测试 |
| 五主页尺寸 | 320/390/430 × 深浅主题 × 五主页共 30 组：root/main 无横向溢出，按钮均有文本或 aria-label |
| 详情尺寸 | 320px 浅色下习惯详情、戒烟、专注历史、收入分类四入口无整页横向溢出 |
| 交付状态尺寸 | 两主题三宽度共六组无横向溢出 |
| 长分类名 | 320px 输入长中文样本，表单 320px/预览 290px，scrollWidth 未超出；没有据此声称所有长内容已测 |
| 收入分类全部归档 | 通过 UI 归档唯一收入分类，新增收入输入金额后保存被阻止，明确提示创建/恢复分类 |
| 既有规则回归 | C1 专注、C2 戒烟、C3 分类三个实际控制器断言脚本均通过 |
