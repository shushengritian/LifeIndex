# G4 C3 分类管理验证

2026-09-19。本地合成内存原型，无生产代码/数据库/依赖/部署变更，不是真实 iPhone 验证。

## 已执行路径

- 新分类空名称拦截；填“早餐”并选择餐饮图标/橙色。模拟失败保留表单，重试后仅生成一个分类。
- 在记账新增入口选择早餐、保存 12 元记录。分类引用数为 1；改名早午餐后历史同步，不改变金额。
- 归档早午餐：新账目分类列表排除它；原账目显示已归档，编辑表单仍可保留并保存原分类。
- 归档专注的阅读分类：新专注选择器排除阅读，原完成记录仍显示阅读（已归档）。
- 运动散步改名户外步行，两条历史同步；原记录编辑选择器显示新名，保存仍保持记录身份。
- 归档唯一收入分类后显示“暂无可用分类”和创建入口；从已归档列表恢复后，使用中回到 1，引用仍为 1。
- 390px 深浅分类列表和编辑表单截图检查；320/430px 编辑 dialog clientWidth = scrollWidth，无横向溢出。
