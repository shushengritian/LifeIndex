## 1. 视觉方向与取舍

以 MOZE 的信息层级、Things 的操作秩序作为用户指定的借鉴原则，不声称本轮进行了新竞品研究，不复制品牌资产。选择“暖白底色 + 松绿强调 + 清晰数字”，深色独立配为炭绿底色，不直接反相。情绪来自留白和轻微暖色，不靠大渐变、玻璃、插画或浓阴影。

重要信息分三层：页面标题与当前任务；核心数字与状态；时间/来源等辅助说明。健康不显示跨模块评分，不用一个巨大综合仪表盘。记账保持日历入口，月汇总在其下；金额不把支出涂成错误红色。

两个有实质取舍的密度方案：

| 方案 | 布局 | 适用与代价 |
| --- | --- | --- |
| 舒展（推荐） | 卡片内边距 18，卡片间距 18 | 记录和状态更易分组；健康习惯区需要继续向下滚动 |
| 紧凑 | 内边距 14，卡片间距 12 | 首屏容纳更多内容；分组呼吸感较少 |

两方案字号、触点和业务信息相同，不靠缩小文字提高密度。密度开关是审稿工具，不代表新增产品设置。颜色方案只给一个主方向，避免大量仅换色的假选择。

## 2. 双主题语义令牌

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| canvas | `#F6F7F2` | `#141C18` | 页面底色 |
| surface | `#FFFFFF` | `#1F2A23` | 内容卡/表单/导航 |
| surface-secondary | `#EEF1EB` | `#2A362D` | 次层背景、未选区域 |
| text-primary | `#1F3029` | `#EDF2E9` | 标题、金额、输入 |
| text-secondary | `#5E6C63` | `#AFBEAF` | 日期、说明、导航标签 |
| separator | `#DCE2D9` | `#3C4B3E` | 非必要装饰分隔，不能独自表示交互边界 |
| control-border | `#819086` | `#879B87` | 输入框、必要控件边界 |
| accent | `#276650` | `#ACD5B5` | 当前主动作/选中日/打卡 |
| on-accent | `#FFFFFF` | `#172B1E` | 强调底色上的文字图标 |
| accent-soft | `#E1EEE4` | `#2B4634` | 次操作、选中导航 |
| danger | `#A23930` | `#FFB4A5` | 错误、删除等风险 |
| danger-soft | `#FAE9E5` | `#4B2B25` | 错误与风险背景 |
| warm / warm-soft | `#96633A` / `#F3ECDF` | `#E0BE92` / `#3D3427` | 部分类别辅助色，不表达财务正负 |
| focus-ring | `#237566` | `#A9DFC4` | 3px 键盘焦点轮廓，外偏移 3px |

状态不能仅由颜色区分：收入/支出带符号和标签；日期选中有实底形状及 aria-pressed；打卡有勾和已完成；戒烟未记录明确文字；错误有说明，字段标记 aria-invalid。

本轮关键颜色对计算（sRGB）：浅色次级文字/白底 5.52:1、次级文字/页面 5.13:1、主按钮文字 6.77:1；深色次级文字/卡片 7.64:1、主按钮文字 9.24:1；错误文字/错误底浅 5.64:1、深 7.37:1；控件边界/卡片浅 3.35:1、深 5.00:1。仅证明列出的颜色对，不代表全应用 WCAG 审计通过。

## 3. 排版、数字与空间

- 使用系统字体栈：`-apple-system, BlinkMacSystemFont, PingFang SC, sans-serif`；中文优先，无外链字体。正文 16/24，次说明 13/19.5，页标题 28/35，区块标题 16/24–20/30，重要数值 28–38，金额输入 40（窄屏 36），字重 400/500/600。更小的 11px 仅用于导航和日历有限标记，选日明细提供完整读取。
- 数值使用 tabular-nums；字段名称不随中英数字错位；货币/单位与数值分级显示。月汇总 15px，不争夺日历与日明细层级。
- 间距基准 4/8/12/16/18/24/32；内容表面圆角 20，列表 18，按钮 13–14，选择器 8–12，底部表单顶角 26。外部审稿手机边框不是产品装饰。
- 只为模态/分段选中提供必要阴影；深色主要靠表面层次和线条，不堆黑阴影。图表不因深色反转正负意义。
- 长名称换行，完整金额在明细保持可读；日历金额缩写仅作为索引，显式说明 `k = 千元`，选日后的明细显示完整值。此为展示格式，不改变整数金额或汇总算法。
- 实现时设计 token 应落成语义 CSS 变量与统一排版类，当前仅存在隔离样板，不替换生产 CSS。

## 4. 按钮系统

| 类型 | 使用 | 状态与限制 |
| --- | --- | --- |
| 主按钮 | 保存记录、开始计划等当前任务唯一主动作 | 强调底+高对比文字；按下轻缩放；焦点轮廓；保存中宽度不变、不可重复执行 |
| 次按钮 | 记录空状态、重试、继续查看 | 浅强调底；不得和主按钮同等抢眼 |
| 普通按钮 | 取消、返回预览 | 表面底、可辨边界，稳定触点 |
| 图标按钮 | 加号、关闭、编辑入口 | 图形 20–22，容器至少 44×44；有明确 aria-label；不为含糊概念强用图标 |
| 行式入口 | 历史、设置子项 | 标签 + 对齐的右向箭头；生产整行可点击，不只是小箭头；样板仅用于演示入口语言 |
| 危险按钮 | 删除、替换数据、放弃更改 | 独立危险色，与对象/后果确认配对；默认焦点不是危险动作 |

共同状态：默认、按下、键盘焦点、禁用、处理中、成功、失败。禁用使用次表面/文字，但不得让原因只能靠颜色表达；处理中明确“保存中…”并防重复；成功轻反馈+返回来源；失败回可编辑表单及内联提示，不把按钮变红就算处理完毕。

原型下方有静态状态标本；真实表单可体验校验、保存中、合成失败/重试、成功和放弃确认。暂不增加假“撤销删除”。

## 5. 图标系统与资源边界

复用现有 LifeIndex 的 24px 线性方向，以原创 SVG 补齐示范操作/模块图标，统一 1.8px stroke、圆端圆角、20–22px 显示尺寸。本轮没有混入另一套外部图标，没有下载 MOZE/Things 资产，也没有新增依赖。

通常优先成熟图标家族，但现有仓库已有自有导航图标，当前选择扩展同一语言以避免本阶段变更依赖和授权不明。若 G3 审核认为个别符号不够直观，可在实现前比较单一成熟家族并登记许可证；不能临时混用多套。

| 语义 | 图形 | 文字/可访问要求 |
| --- | --- | --- |
| 今天 / 记账 / 专注 / 健康 / 设置 | 日历勾 / 钱包 / 秒表 / 心形脉搏 / 齿轮 | 五项标签常显；选中有背景和文字强化 |
| 新增 / 关闭 / 编辑 / 删除 | 加 / 叉 / 铅笔 / 垃圾桶 | 标签说明目标，如“记录体重”，不是仅“加号” |
| 体重 / 运动 / 戒烟 / 习惯 | 秤 / 鞋 / 叶 / 书 | 模块标题始终显示；叶不单独承担“戒烟”识别 |
| 分类 | 餐具 / 杯 / 交通 / 方格等 | 是合成分类示例，不新增产品预设分类 |
| 导出 / 完成 | 向下箭头 / 勾 | 导出必须带“导出备份”文字，不让箭头猜方向 |

资源登记：`prototypes/g3-visual.html` 的 `paths` 为本轮代码原生示例，无第三方资源；项目原有 license 选择不被本设计擅自修改。SVG 是设计源，G4/G5 再决定实际组件资产映射。

## 6. 公共组件规格

| 组件 | 外观与交互 | 必须覆盖状态 |
| --- | --- | --- |
| 导航/标题 | 五项图文导航，选中浅底；页标题和主新增分列 | 默认/选中/忙碌阻止穿透；safe-area 留底 |
| 列表行 | 类别图标块、标题/时间、尾部完整数值 | 正常/长内容/读取失败/删除后焦点 |
| 摘要 | 核心数字突出，单位/时间弱一级 | 无记录用“—”或明确空状态；真实零值仍是 0 |
| 日历 | 周一开头、52px 行高、净额标记、选中实底 | 月切换/选日/空/有收支/大额；完整金额读出路径 |
| 趋势 | 单一主线，无装饰大面积填充；详情才承载坐标和完整统计 | 无数据/稀疏/长时间段/文字替代，样板线为明确示意 |
| 热力图 | 低到高离散强度+图例；状态按计划语义分开 | 未记录/非计划/完成/选日；不是连续天数的替代，G4 具体稿 |
| 表单/选择器 | 标签常显，等宽日期/备注；图标分类格；清晰主次提交 | 输入/校验/保存中/失败/成功/放弃；不只有正常截图 |
| 底部表单 | 顶部标题+关闭，内容滚动，底部取消/保存 | 背景 inert、焦点、键盘可达、保存中禁止关闭；不得点击穿透 |
| 风险确认 | 对象与后果、继续/放弃的明确命名 | 默认安全焦点、忙碌、失败、取消；不使用原生 confirm/prompt |
| 非阻断反馈 | 短文本+状态图标，错误不依赖转瞬即逝 toast | 成功/离线/更新可用；更新不能吞草稿 |
| 空/加载/错误 | 空有起步动作；加载骨架和文字；错误保留重试 | 读取失败不得显示“没有数据” |

这是全系统的视觉契约，不是以上全部组件已完成高保真。G3 样板覆盖导航、日历、列表、摘要、趋势示意、表单、确认与反馈；热力图、完整设置选择器、更新/备份专用状态在 G4 扩展并验收。

## 7. 三个样板细则

### 记账首页

优先顺序：标题/新增 → 月份日历 → 月收入/支出/结余 → 所选日明细。合成月收入 8,500.00、支出 894.00、结余 7,606.00；9 月 16 日 3 笔合计支出 76.00，均从同一个合成集合计算，避免展示稿数字自相矛盾。原型月份只演示 2026 年，非真实时间导航功能。

日格在窄屏无法全部达到 44px 宽：保留 52px 高度、3px 间隔和选日明细替代，不谎称每格触点都达标。G4 再验证误触和更大字号下的替代日期选择。

### 健康首页

体重突出最近值与时间，趋势作为辅助；运动只展示既有周次数/时长；戒烟明确“计划已开始，不代表连续无烟”，今天未记录单独表示；习惯保留直接打卡。四组共用标题、主动作、次入口秩序，不用不同风格四个小系统。

深浅主题均支持空、读取中、读取失败和正常状态。详情/其他表单入口点击会明确告知 G4 展开，不用静默假按钮。完整历史与热力图不在 G3 扩展成完整应用。

### 新增账目表单

类型 → 金额 → 分类 → 日期时间 → 可选备注 → 取消/保存。主要关注金额输入和分类选择，不增加假数字键盘；系统输入能力保留。切换收入/支出清除不适用分类。选日新增继承该日；已有脏输入时阻止用新入口覆盖。

同一表单展示默认、字段错误、保存中、写入失败、成功、放弃确认；失败保留输入，默认焦点继续编辑。这里是独立展示面，不是生产路由上的实际模态；真正背景 inert/焦点循环/软键盘行为在 G4/G5 继续验证。

## 8. 动效、响应式和设备限制

按下反馈 140ms，幅度约 2%；减少动态效果时去掉变换与过渡。加载骨架默认静态，不做持续闪烁。成功反馈不依赖动效才可理解。

目标宽度 320/390/430 CSS px；文字和触点不因紧凑模式变小。输入至少 16px，手机键盘展开时操作可滚到；真实产品底栏/表单须结合 `env(safe-area-inset-bottom)`，不能复制审稿稿中“9:41”示意栏到产品。样板受控视口和滚动只是审稿布局，不是 iPhone 系统行为证据。

G4 还需补全 200% 放大、长金额/长习惯名、语音辅助、所有主题状态和真实字段完整矩阵；G5 真机键盘/后台/安装/更新单独验收。
