## 实际剩余问题（1 项）

### B-R2-01 · P2 · 无记录月份仍绘制带逐日数据点的零值趋势

类型：**客观的简报一致性/空态语义问题，不是审美偏好。** 不影响保存，也不是金额汇总算错。

- 实际步骤（主代理）：记账 → 报表 → 收入 → 上个月到 2026年8月（O1#2–4）；另一次切全空样本 → 报表（E#2）。
- 实际：月汇总为 0.00 元、0 笔，分类写“本月暂无收入/支出”；趋势 DOM 仍是一张逐日图像，8月有 31 个“收入 0.00 元”，全空 9月有 20 个“支出 0.00 元”。`app.js:285–288` 将空数组按每一天补零，无条件生成圆点与折线；`:309` 空报表也调用它。[空样本图](../reviews/operation-refresh/report-empty-r2.png) 支持上方 0 笔/暂无状态；图中趋势主体在首屏下方，折线结论以 DOM 和源码为据，不冒称首屏已完整展示。
- 预期：BRIEF 明确要求“空数据不画假趋势”。无记录应呈现“暂无记录，无法形成趋势”等空态，避免把没有记录表达成每天都有零值观测。月汇总 0.00 可以保留。
- 最小处置建议：仅在所选类型/月份存在记录时绘制数据折线与圆点；零笔时使用文字空态。无需预算、账户、导出或后端，也无需另开第三轮审核。

截至冻结证据，未发现需要继续保留的 R1 问题；不为凑满五项把尚未验证的边界、截图拼接或个人喜好列成缺陷。
