## 入口与运行

- [独立原型](../prototypes/operation-refresh/index.html)，无需构建。预览地址：`http://127.0.0.1:4176/operation-refresh/index.html`。
- 支持 `?theme=light|dark&view=today|health|focus|finance|settings`。参数仅选择主题和初始页；不接受业务写入。
- `embed=1` 隐藏壳外审稿工具，适合双主题 390 × 844 iframe。App 底栏完整保留，各 iframe 状态独立。
- 外层审稿工具提供日常/空/长内容样本、下一次保存失败、推进正在运行的计时至结束。长内容样本含长分类名与大额账目，供报表布局复核。折叠工具不会进入 App 页面内容。
- `app.html` 是真正的 App 内容，`index.html` 以不授予 same-origin 的 sandbox iframe 承载它；业务代码在 opaque origin 中运行，不能读取 localStorage / IndexedDB。两层 CSP 禁止连接、worker、图片、字体、表单外发与远程资源；仅同目录脚本/样式和外层本地 iframe可加载。没有文件选择、下载、存储或网络调用。
- 应从独立预览来源打开 index.html；直接打开 app.html 不具有外层 sandbox 限制，但代码同样没有存储访问。正式验收入口为 index.html。

## 设计契约

模式为 Operate。依据 Impeccable 的手动上下文、Operate 与 craft-floor，保留 Ocean 既有视觉语言。没有运行 launcher、engine、hooks 或 skill 的自动批评流程。

THESIS：页面内容直接承接日常操作；短输入进入统一 sheet，历史与管理使用子页。

OWN-WORLD：深海蓝和雾蓝白，青蓝仅承担主操作/选中态，橙/紫/青绿区分语义图标。系统字体、24px SVG、分隔记录行与紧凑数据表达。

STORY：读到状态、就地完成动作、看见结果；保存失败仍能找到原输入。

FIRST VIEWPORT：今天优先呈现习惯打卡与专注导航；健康优先体重及目标、运动和习惯节；专注将计时与播放/结束合为圆环主控件，待保存以实际时长为主读数；记账保留日历金额、月结余/支出/收入、每日支出曲线和流水，详细分类分布移入明确的「报表」入口；设置四组列表。没有模拟系统状态栏。

FORM：既有 Ocean 世界内的结构与交互优化，用户已指定 code-led 隔离原型。手动模式无 seed key，未伪造流程结果。

FINISH：R1、R2 两轮独立审核完成，用户要求后的定点空态收尾完成。保留历史审核记录与未测边界，不再扩展自检或开启第三轮代理打磨，交用户最终验收。

## 交互规则

| 场景 | 规则 |
| --- | --- |
| 主操作 | 48px 以上。专注为圆环内 58px 播放/停止控件，旁有永久短文字说明。运行时仅「提前结束」与下方弱化「取消本次专注」，无暂停。 |
| 内容动作 | 44px 图标按钮；有可访问名称。打卡在行尾，名称行进入详情。新增在节标题右侧。 |
| 导航 | 五项顺序固定。内容独立滚动，底栏独立栅格行。详情/管理记住实际入口来处、触发点与原页滚动；设置进入戒烟管理返回设置，今天进入习惯详情返回今天。初始展示参数不抢焦点，用户主动导航仍有焦点管理。 |
| 编辑 | 原生 dialog 实现焦点隔离；form 为三行 grid，头尾不滚动，中间普通 div 独立滚动，fieldset 只承担批量禁用。错误 focus 使用 preventScroll，再只调整内容区滚动。真实表单标签、范围/必填校验；保存中约550ms禁重复提交和退出。短视口实际几何待浏览器复核。 |
| 草稿 | 关闭和 Escape 检查输入变化，确认放弃或继续编辑。失败不重建表单，保留输入并可直接再保存。 |
| 删除 | 编辑详情内的低权重文字入口，确认后才修改内存。失败保留确认与原记录。 |
| 快速写入失败 | 打卡等原地操作失败时不改变记录；页面上方显示错误和重试。 |
| 专注 | 事项必填、不能全空白，开始与详情编辑均去首尾空白。Date.now 与 startedAt 的差值是事实来源，250ms重绘不累加时间。运行展示剩余/已专注/目标；待保存主读数为实际时长并明确重试。自然结束自动模拟保存，提前结束经确认，取消不写历史。Today、专注页与历史统一保留秒数，今日/本周汇总只计已完成且保存的会话。 |
| 习惯 | 今天打卡独立于历史查询；历史日期和热力格只能查看，处理函数拒绝非今天的写入目标。当前连续、最长连续、当月完成率/次数、累计由样本计算，未完成的今天不打断既有连续，非计划日跳过。 |
| 分类 | 一级彩色SVG，记账二级仅名称；专注/运动仅一级，UI和编辑/写入分支均阻止新增二级。三点使用紧凑SVG＋文字菜单行承接编辑/排序/归档；归档保留历史引用。 |
| 记账保存 | 新增/编辑异日账目后，保留原记账浏览日/月或Today页面。持续展示所存日期与「查看记录」，只有主动点击才定位保存日期。 |
| 体重 | 相同日期/时间以较新的创建id优先，摘要、曲线末点和历史采用同一规则。 |
| 报表 | 记账页头为图表SVG＋「报表」。进入继承浏览月份，子页独立切月/收支；按一级分类聚合二级账目，以水平条形图表达金额和占比，按金额排序。每日趋势使用同月逐日金额折线。所选日期范围/收支类型无记录时显示「暂无记录，无法形成趋势」，不生成数据图像；有记录范围的缺项日才补零。主页七日支出共用此规则。返回恢复原记账月/日/滚动，不增加底导航。 |
| 恢复 | 内置模拟样本 → 格式/版本检查 → 预览 → 明确替换确认 → 模拟内存替换。错误不改变当前记录。不读写/下载文件。 |
| 戒烟 | 计划经过天数不等于连续无烟；确认仅截至当时。吸烟记录撤销同一天未吸烟确认，删除吸烟记录不自动恢复确认。隐藏健康入口不删除历史，设置中仍能管理。 |

## 视觉与实现建议

CSS 使用当前 Ocean 的语义色：深色 `#101f35` 背景、`#192d45` 表面、`#79d6fa` 主色；浅色 `#f1f6fb` / `#ffffff` / `#126590`。文本 `#edf4ff` / `#172c46`，辅助 `#afc2d8` / `#526a82`。列表正文15px、表单16px、节标题17px、页标题28px，数据等宽数字。面板16px、控件10–12px，表单上角24px。没有外部字体或图片。

建议获批后分批实现：先共享导航/编辑/反馈壳；再今天和记账；再健康各子域；再专注状态映射；最后设置/分类/备份。每批保留生产 repository 与迁移契约，避免将原型内存实现移入生产数据层。需为关键写入、失败/重试、焦点返回与恢复确认做生产回归。正式实施必须另获授权。
