# LifeIndex 全应用操作体验优化 — 设计简报

日期：2026-09-20。状态：用户授权设计与独立审核，尚未验收，不授权生产实现或部署。

## 目标与边界

以 3.0.0 为产品事实，优化今天、健康（体重、运动、习惯、戒烟）、专注、记账、设置的全部操作层级与关键流程。保留 Ocean 双主题、彩色分类图标、曲线表达、五导航顺序「今天 / 健康 / 专注 / 记账 / 设置」；不是重做品牌，也不是删除文字按钮。

用户目标：从重复的大文字按钮、导航按钮和确认弹窗，转向与内容结合、可发现、操作结果明确的手机应用。主要用户为 iPhone 单人使用者；模式为 Operate。没有新账户、后端、云同步、快捷指令记账或健康建议功能。

本轮仅允许修改独立原型及设计/计划文档。生产 `src/`、`public/`、应用版本、依赖、IndexedDB、SW、Git 发布均不改。不重新开启已关闭的发布目标。真实数据不读取、不写入；全部样本合成且仅内存，刷新重置。不得把模拟文件操作、后台计时或截图检查记为真实 iPhone 验收。

## 设计原则

- 一处任务区域只有一个主要动作；主要动作、内容操作、导航、管理/危险动作采用不同视觉权重。
- 高频操作靠近内容，已有明确上下文的新增可用图标；图标按钮有可访问名称、稳定触控区。取消、覆盖、删除保留可理解的文字。
- 历史/统计是导航入口，优先章节链接或列表行；短记录用统一编辑面板，复杂管理用独立子页；不把所有流程都塞入弹窗。
- 保存后返回原上下文并显示真实模拟结果；失败保留草稿；脏草稿关闭需明确选择；加载/保存时避免重复提交。
- 不添加专注暂停：仅开始、持续计时、提前结束、取消、完成与待保存重试。剩余/已专注/目标分开，汇总只含已完成且保存的会话。
- 记账保留可点击日历、月汇总、二级分类；一级彩色图标，二级只名称。点击账目进入编辑，删除不与新增同等突出。
- 戒烟计划经过时间不等同连续无烟；「截至现在未吸烟」不等同全天。保留计划、吸烟/烟瘾记录、回顾及设置隐藏/恢复入口语义。
- 设置保持分类、外观、数据与安全、其他四组。恢复仍先校验/预览，再明确确认替换；不能以轻量化为由去掉数据风险保护。
- 内部滚动与底部导航分离；弹层退出恢复焦点与滚动位置。深浅主题、320/390/430px、键盘和减少动画均纳入检查。

## 本轮补充：轻量记账报表（2026-09-20）

用户提出把记账下方分类改成柱状图/折线图，或提供独立报表入口，并授权继续设计。采用独立「报表」子页提案，图表图标配文字入口，不增加底部导航。主页仍保留日历每日金额、月结余/支出/收入、每日支出趋势和流水；详细分类分布移入报表。

报表继承记账浏览月份，可按月查看支出/收入：分类用横向条形图呈现金额与占比，日期趋势用折线。二级汇总不得与一级重复计数。仅聚合已有账目，不增加预算、资产、预测、导出或后台。返回保留来源记账月/日与滚动，不让报表选月悄悄修改主页上下文。空数据不画假趋势，图表有文字金额/日期含义；深浅主题与长分类名可读。

此项合入本轮 R2，是用户新增设计要求，不是第三轮自动打磨。生产 PRD/LLD 和实现仍须用户验收后另行授权。

## 团队与审批流程

主代理：产品协调、范围/文档、浏览器证据和汇总；设计代理 A：原型及控件规范；体验审核代理 B：独立检查可发现性、任务流程、视觉层级；工程审核代理 C：独立检查范围一致性、移动端/无障碍与异常状态。

审核员不负责修改原型，第一轮不先读设计师的自我评价或另一名审核员的意见。发现必须包含位置、证据/步骤、严重度与建议；设计师逐条回应采纳或保留理由。先一轮独立审核，汇总修改后最多一轮复审，不自动迭代至「所有人赞同」。主观审美分歧留给用户。

最终交付：全模块操作清单、设计契约、可交互原型、两主题代表截图、审核与处置记录、实施分批建议。用户确认后才另行推进生产代码。
