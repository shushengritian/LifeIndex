| 流程 | 主代理采集目标 |
| --- | --- |
| 编辑面板失败 | 320 短屏深浅主题：金额与分类→模拟失败→错误可见、头尾不交错→输入保留→重试；记录应用视口小于外层时的工具占用 |
| 草稿和焦点 | 输入→Escape→继续→再取消；确认只关闭顶层、放弃后导航可用 |
| 专注校验 | 空/纯空白事项不能开始；有效事项可开始，跨页返回仍运行 |
| 专注结束失败 | 提前结束→模拟失败→本次结果与待保存明确→重试只一条，今日/本周/Today/历史精确秒数 |
| 专注取消 | 新会话取消，不新增历史/汇总；详情编辑清空事项校验 |
| 习惯 | 历史选日只读、热力日期可查看；今日打卡与统计相符；Today 来源返回正确 |
| 记账 | 每日金额和结余优先；跨月新增后保留浏览月/日，明确查看才跳转；Today 保存返回 |
| 健康 | 同时间新增体重后摘要/图线/历史一致；保持不引入真实数据逻辑 |
| 返回上下文 | 设置到戒烟管理返回设置；戒烟内管理返回概览；Today 习惯详情返回 Today |
| 分类 | 记账二级仅名称；专注/运动无不可消费的二级入口；分类菜单改为轻量行操作 |
| 用户追加报表 | 从记账进入报表→继承月份→分类条形图与金额/占比→切收入/支出→切空月份→返回原记账月份/选日；趋势横轴为日期，条形类别为分类，二级不重复汇总 |
| 初始/响应式 | 加载不抢父页面焦点；五模块双主题 390/320；视口与导航存在证据不泛化为所有控件已测 |
