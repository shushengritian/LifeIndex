## 方法

一个设计代理制作隔离原型；两个独立审核代理先从当前产品建立各自检查依据。第一轮审核只提供用户要求、原型与可观察状态，不提供设计师自我评价及另一名审核员结论。主代理负责最终汇总，不将代理意见一致视为用户验收。

第一轮：体验审核 B 与工程审核 C 独立检查。修订：设计代理逐条回应与修改。第二轮：两名审核员只复核修订及关联流程，仍有争议或缺口明确保留，不启动第三轮自动打磨。

## 结论口径

- P0：涉及真实数据/隐私/授权边界，立即停止相关操作。
- P1：关键任务失败、数据语义错误、输入丢失或主要操作不可达。
- P2：可复现的视觉、反馈、可发现性或一致性问题。
- 偏好：有多个合理设计选择，交用户决策，不伪装成客观缺陷。
- 未测/未覆盖：明确说明；不把生产契约、设计意图或源码存在当测试通过。
