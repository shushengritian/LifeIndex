## 建议验收路线

先用 390px 常规高度看整体，再切 320px 看紧凑程度。连续流程用 App 内部导航，不用上方模块切换（会重置）。

1. 今天：点行尾打卡，再点习惯名称查看详情，感受动作与导航的区别。
2. 记账：点日历日期、右上角新增、选择一级/二级分类；改到其他日期保存，检查返回与查看结果。再进入「报表」，看分类条形图、每日趋势、月份/收支切换与返回。
3. 专注：输入事项，点圆环内播放；提前结束，检查本次结果和历史。取消不应产生记录。
4. 健康：新增体重、进入历史；从不同入口进入习惯或戒烟管理，检查返回位置。
5. 设置：进入分类和三点菜单；走模拟恢复预览后取消。重点判断菜单是否仍笨重、危险动作是否足够清楚。

需要检查失败状态时，打开审稿工具，先选择“下一次保存失败”，再操作保存；失败应保留输入。此路线是用户验收建议，不是已通过声明。
