## 用户新增：独立记账报表

本项是R2期间用户明确授权的设计补充，沿主代理确定的轻量子页方向，不是新增第三轮。

- 已实现：记账页头图表SVG＋「报表」入口；主页保留日历、月结余/支出/收入、每日支出曲线和流水，原详细分类分布移至报表。
- 报表继承进入时记账月份，自己维护月份及支出/收入选择。按现有账目一级分类汇总，包含二级记录及已归档引用；水平条形图呈现金额/占比，类别按金额排序；每日折线呈现时间变化。没有用折线连接无序类别。
- 总额和条形分组均从同一合成账目集合计算。当前月趋势截至合成今天，其他月覆盖整月；无数据显示明确空态及零趋势。金额完整显示并允许换行，长名不截断；条长为真实比例，极小占比文字标为「不足0.1%」。
- 返回通过同一来处机制恢复原记账月/日/滚动。没有新底导航、预算、资产、报表导出或新数据业务。
- 已执行DOM检查：默认月支出1,014.00元/22笔，其中餐饮1,008.00元、交通6.00元；切收入12,800.00元/1笔；切空月无条形；返回仍为原9月19日与原滚动值。长名/大额样本金额与条形比例检查完成，空样本有明确空态。13组检查最后一组覆盖本项。
- 尚未验证：320短屏和双主题中的报表金额换行、类别长名称、条形视觉区分、图表可读性与实际返回滚动；交主代理/B/C取证。没有自判报表验收通过。
