# Ocean 视觉参考

当前版本使用深海蓝与冷白雾蓝两种主题。实际 token 以 `src/styles/global.css` 为准；下表为核心语义参考。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| canvas | #f1f6fb | #101f35 |
| surface | #ffffff | #1a2d45 |
| text | #172c46 | #edf4ff |
| muted | #516982 | #a9bdd4 |
| accent | #126590 | #71d5ff |
| divider | #cfdeec | #354c64 |

字体采用系统栈，表单输入至少 16px，数字使用 tabular-nums。单位、标签与数值层级清晰；正文、辅助文字及选中状态均需验证对比度。

图标使用原创 SVG，常用画布 24×24，圆端描边；可见图标尺寸与可点击区域分开设定。图标按钮目标为 44×44 或更大。输入框、分段控件、底部表单使用一致圆角和间距。

渐变仅辅助体重和专注层次；图表线与点表示真实数据。聚焦状态可见，错误同时有文字提示。动画服从 prefers-reduced-motion。更多交互规则见 [设计指导](UX_UI_GUIDE.md)。
