# G3 Ocean Design System — PROPOSAL ONLY

## Overview

2026-09-18。仅供 G3 三模块、双主题共六个审稿视图使用，不是六套独立主题。本文不是已批准的根目录 DESIGN.md，也不是 .impeccable 配置；现有生产实现保持不变，不授予生产实现或发布权限。

用户选定 A（Tide Guide）的海蓝色调、曲线和彩色图标为主参考，B（Moonlitt）的专注氛围为辅助；不采用 C（CapWords）贴纸方向。以清晰数据、紧凑分组和明确主动作表达轻量生活记录。

依据：[方向约定](G3_OCEAN_DIRECTION.md)、[现有评审与验证记录](G3_OCEAN_REVIEW.md)、[样板 CSS](prototypes/g3-ocean.css) 与 [样板 JS](prototypes/g3-ocean.js)。值来自当前原型，包含末尾覆盖规则；仅手动提取，未运行 launcher、engine、hooks 或浏览器。测试结果和最终 verdict 由评审文档承载，本文不代为验收。

## Typography

共用字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif`；根字号/行高为 `15px/1.5`，正文启用 `tabular-nums`，没有外部字体或独立等宽字体。

| 角色 | 当前值 |
| --- | --- |
| 页标题 | 28px / 700，字距 −.03em |
| 区块标题 / 弹层标题 | 17px / 650；弹层覆盖为 20px |
| 列表标题 / 金额 | 14px / 600；金额 16px / 600 |
| 月汇总 | 15px / 600；≤350px 时 13px |
| 表单输入 / 主按钮 | 16px；主按钮 15px / 650 |
| 专注计时 | 64px / 300，行高 1.4，字距 −.04em；≤350px 时 58px |
| 体重主值 | 38px / 550，行高 1.25；单位 14px |
| 辅助与索引 | 通常 10–13px；日历金额与体重纵轴为 9px |

小字号是本轮现状，不是通用可读性下限；完整金额可由日期可访问名称及明细读取，大字检查仍属评审披露的待办。

## Layout

手机容器纵向排列，主内容独立滚动；内容内边距 `6px 20px 22px`，五导航保留在底部。导航最小高度 76px，底部内边距 `max(14px, env(safe-area-inset-bottom))`。

共用页头将标题与新增/历史入口分置两端。日历七列、间距 3px；月汇总三列；分类选择四列、间距 8px；日期/时间默认两列、间距 12px。列表以分隔线组织，常规记录行最小高度 62px。

≤350px 时内容左右边距 15px、日期格高度由 46px 改为 44px、分类间距 5px、日期/时间改为单列。字号同步缩小见 Typography；这不是全量响应式或真实 iPhone 验证。

## Elevation & Depth

常规内容以色阶与细分隔线分层，不使用通用卡片阴影。体重面板使用 `linear-gradient(155deg, var(--raised), var(--surface))`；专注区域使用从 `--sky` 到透明的底部径向渐变。

模态阴影为 `0 -12px 60px #0005`，遮罩为 `#050d1b99`。趋势面积使用主色透明度 `.2 → 0`；Toast 反转为主文字色底、页面色文字。

## Shapes

2026-09-19：设置图标修正为以 (12,12) 为中心的八齿对称轮廓，中心圆半径 3.2；显示尺寸与描边体系不变。记账浏览日期只通过日历及月份箭头选择，重复的日期跳转输入已移除。

输入框与图标按钮圆角 12px，主按钮及分段外框 14px，新增按钮 15px，体重面板与导航项 16px。分类项、常规图标底块、次按钮与 Toast 为 13px；分段内部按钮 10px。

底部表单仅上角 24px；居中确认框四角 20px。原创 SVG 使用 24×24 坐标系、1.7 圆端圆角描边，常规显示 23px，小图标 17px；24px 是画布而非统一显示尺寸。

## Components

- 按钮：主按钮全宽、最小高度 50px，使用主色/主色上文字；次按钮最小高度 47px、内边距 `10px 16px`。通用图标按钮最小 44×44px，悬停使用抬高表面。按下缩放 `.97`，禁用按钮透明度 `.6`。
- 焦点与输入：控件 `focus-visible` 为 3px 主色描边、偏移 3px。通用字段最小高度 46px、1px 边界、内边距 `10px 12px`；专注事项输入为无边框表面色。错误使用文字消息与 `aria-invalid`，未定义额外错误边框样式。
- 分段与分类：分段选中项使用抬高表面与主文字；分类选中项使用主色边界和柔和底色，以 `aria-pressed` 表达状态。
- 导航与记录：今天、记账、专注、健康、设置五项标签常显，选中项用柔和底色与主色；今天/设置入口仅说明后续范围。记录行组合分类图标、标题/时间及右侧数值。
- 趋势：共用真实合成点位折线，描边 2.4，最新点半径 4；周支出图显示高度 67px，体重图最终覆盖为 104px，并保留 kg 与纵轴范围。专注弧线按时间比例更新，无暂停。
- 表单与确认：原生 dialog 隔离背景和焦点；底部表单最大高度 90dvh、头尾吸附，确认框最大宽度 380px。脏输入退出需确认，保存中禁重复及退出，失败保留输入并可重试。
- 保存反馈：Toast 显示 2600ms；账目保存到非当前浏览日期时另有持续的“查看记录”入口，健康备注可在历史中回看。记录仅存各原型内存，刷新重置。
- 动效：按钮颜色/缩放 150ms，Toast 透明度 180ms，弹层入场 200ms ease-out、上移 16px；减少动态效果时取消动画、过渡及按下缩放。

## Do's and Don'ts

- Do：三模块共享上述双主题语义、字体、图标与控件；保持 A 主/B 辅的既定方向。
- Do：曲线来自实际样本，数值附单位；保持紧凑层级、明确新增入口与保存后的可回看反馈。
- Don't：引入 C 贴纸风格、复制参考 App 素材，或用装饰波形伪造数据趋势。
- Don't：将窄屏日历、40px 分段等所有触点声称为 44px 达标；不将本稿当作完整 WCAG、真机或生产回归证据。
- Don't：将本提案提升为生产设计真相或配置；G3 审核通过后仅进入 G4 全量高保真原型，生产实现仍需明确授权。
